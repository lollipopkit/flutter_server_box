ServerBox is a Linux server monitoring and management tool.

Key features:
• View status charts for CPU, sensors, GPU, and more
• Manage servers with an SSH terminal and SFTP
• Manage Docker containers, packages, and processes
• Use biometric authentication, push notifications, home widgets, and the watchOS app
• Follow system colors and use the app in multiple languages

Special thanks to dartssh2 and xterm.dart.
