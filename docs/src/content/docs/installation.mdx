Server Box is available on several platforms. Choose the download source for your device.

## Mobile

### iOS

Download Server Box from the **[App Store](https://apps.apple.com/app/id1586449703)**.

### Android

Choose an installation source:

- **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)**: Project release page
- **[CDN](https://cdn.lpkt.cn/serverbox/pkg/?sort=time&order=desc&layout=grid)**: Direct release downloads
- **[F-Droid](https://f-droid.org/packages/tech.lolli.toolbox)**: FOSS app repository
- **[OpenAPK](https://www.openapk.net/serverbox/tech.lolli.toolbox/)**: Third-party app store

## Desktop

### macOS

Download from the **[App Store](https://apps.apple.com/app/id1586449703)** or install with Homebrew Cask:

```sh
brew install --cask server-box
```

The macOS builds support both Intel and Apple Silicon. The DMG build also provides a local terminal; the App Store build is sandboxed and cannot provide that feature.

### Linux

Download the AppImage from **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)** or the **[CDN](https://cdn.lpkt.cn/serverbox/pkg/?sort=time&order=desc&layout=grid)**.

### Windows

Download the portable zip package from **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)** or the **[CDN](https://cdn.lpkt.cn/serverbox/pkg/?sort=time&order=desc&layout=grid)**.

## watchOS

The Watch app is distributed with the iOS app through the **[App Store](https://apps.apple.com/app/id1586449703)**. After installation, configure the servers to show in the iPhone app. The Watch app requires watchOS 10 or later; the iOS app itself still supports iOS 15 or later.
