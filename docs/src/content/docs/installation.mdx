Server Box is available on several platforms. Choose the download source for your device.

## Mobile

### iOS

Download Server Box from the **[App Store](https://apps.apple.com/app/id1586449703)**.

### Android

Choose an installation source:

- **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)**: Project release page
- **[F-Droid](https://f-droid.org/packages/tech.lolli.toolbox)**: FOSS app repository
- **[OpenAPK](https://www.openapk.net/serverbox/tech.lolli.toolbox/)**: Third-party app store

## Desktop

### macOS

Download from **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)**, or install with Homebrew Cask:

```sh
brew install --cask server-box
```

macOS 13 or later is required. GitHub Releases provide `ServerBox-<version>-arm64.dmg` for Apple silicon and `ServerBox-<version>-amd64.dmg` for Intel; Homebrew automatically selects the correct build for your Mac.

The Mac App Store version is no longer updated. Install the DMG over it: its first launch copies the App Store version's data in.

### Linux

Download a package for `x86_64` from **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)**:

- **Debian / Ubuntu (`.deb`)**:

  ```sh
  sudo apt install ./ServerBox_v1.0.N_amd64.deb
  ```

- **Fedora / RHEL / openSUSE (`.rpm`)**:

  ```sh
  sudo dnf install ./ServerBox_v1.0.N_x86_64.rpm
  # or on openSUSE:
  sudo zypper install ./ServerBox_v1.0.N_x86_64.rpm
  ```

- **AppImage (`.AppImage`)**: Download `ServerBox_v1.0.N_amd64.AppImage` (or `_legacy_amd64.AppImage` for older glibc systems such as Ubuntu 22.04 / Debian 12), mark it executable, and run it.
- **Portable archive (`.tar.gz`)**: Extract `ServerBox_v1.0.N_linux_amd64.tar.gz` and run `ServerBox_v1.0.N_linux_amd64/bundle/ServerBox`.

The `.deb` and `.rpm` packages install to `/opt/serverbox`, link `/usr/bin/serverbox`, and register the desktop entry and icon. They are built against glibc 2.35 for compatibility across Ubuntu 22.04+, Debian 12+, Fedora, and openSUSE.

### Windows

Download the installer (`ServerBox_v1.0.N_windows_amd64.exe`) from **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)**, or install with WinGet or Scoop:

```sh
winget install lollipopkit.serverbox
```

```sh
scoop bucket add extras
scoop install extras/serverbox
```

The installer installs for the current user into `%LOCALAPPDATA%\Programs\ServerBox`, without administrator rights, and adds a Start menu entry and an uninstaller. A new version installs over the old one; settings and servers are kept.

The installer is not code-signed, so SmartScreen may show "unknown publisher". A portable zip is also published alongside it (used by the official Scoop `extras` bucket).

## watchOS

The Watch app is distributed with the iOS app through the **[App Store](https://apps.apple.com/app/id1586449703)**. After installation, configure the servers to show in the iPhone app. The Watch app requires watchOS 10 or later; the iOS app itself still supports iOS 15 or later.
