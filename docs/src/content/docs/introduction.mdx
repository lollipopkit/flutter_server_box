Server Box is a cross-platform server management application built with Flutter. It lets you monitor and manage Linux, Unix, and Windows servers remotely.

## What is Server Box?

Server Box provides one interface for common server administration tasks. It is useful for system administrators, developers, and people who run servers at home.

There are two ways to connect to a server: **SSH**, or a **[Monitor agent](/docs/advanced/monitor-agent/)** running on the server. SSH requires no additional software on the server and supports the full set of SSH features. Monitor agent is useful when opening an SSH port is inconvenient; it continuously stores monitoring history, so charts can contain data from before the App connects.

The same server can use SSH and Monitor agent at the same time. The App tries them in the configured order and can fall back to the other connection. Capabilities provided by both connections remain available.

## Key features

- **Real-time monitoring**: View CPU, memory, disk usage, network speed, GPU status, and system temperature
- **SSH terminal**: Use a full-featured terminal with multiple tabs and customizable appearance
- **SFTP client**: Browse and manage server files
- **Container management**: Manage Docker and Podman containers
- **Process management**: View and manage system processes
- **Systemd services**: Start, stop, and monitor systemd services
- **Network tools**: Run iPerf, ping, and Wake-on-LAN (WoL)
- **Snippets**: Save and execute custom shell commands
- **[Agent](/docs/advanced/agent/)**: Ask a model to diagnose and operate a server; every action requires your confirmation

## Supported platforms

- **Mobile**: iOS and Android
- **Desktop**: macOS, Linux, and Windows
- **Companion app**: watchOS
