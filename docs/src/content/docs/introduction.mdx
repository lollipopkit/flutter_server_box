Server Box is a cross-platform server management application built with Flutter. It lets you monitor and manage Linux, Unix, and Windows servers remotely.

## What is Server Box?

Server Box provides one interface for common server administration tasks. It is intended for system administrators, developers, and people who run servers at home.

A server is reached in one of two ways: over **SSH**, or through a **[monitor agent](/docs/advanced/monitor-agent/)** running on it, which the app talks to over HTTP. SSH needs nothing installed on the server and supports every feature; an agent covers hosts whose SSH port you would rather not expose, and keeps its own history so charts are filled in before the app ever connects.

## Key Capabilities

- **Real-time Monitoring**: Track CPU, memory, disk usage, network speed, GPU status, and system temperatures
- **SSH Terminal**: Full terminal access with multi-tab support and customizable appearance
- **SFTP Client**: Browse and manage files on your servers
- **Docker Management**: Manage containers
- **Process Management**: View and manage system processes
- **Systemd Services**: Start, stop, and monitor systemd services
- **Network Tools**: iPerf testing, ping, and Wake-on-LAN
- **Snippets**: Save and execute custom shell commands
- **[Agent](/docs/advanced/agent/)**: Ask a model to diagnose and operate your servers, with each action reviewed before it runs

## Supported Platforms

Supported platforms:

- **Mobile**: iOS and Android
- **Desktop**: macOS, Linux, and Windows
