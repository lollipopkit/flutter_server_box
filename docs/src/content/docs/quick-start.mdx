Add a server, connect to it, and check its monitoring data.

## Step 1: Add a server

1. Open Server Box.
2. Tap **+** to add a server.
3. Select **SSH** as the connection method, then fill in:
   - **Name**: A name used to identify the server in the App
   - **Host**: An IP address or domain name
   - **Port**: The SSH port; `22` is the default
   - **User**: SSH username
   - **Password or Key**: Choose an authentication method
4. Tap **Save**.

### Connect through the Monitor

Use the Monitor instead when opening an SSH port is inconvenient:

1. Install and configure the [Monitor](/docs/advanced/monitor-agent/) on the server.
2. Enable **Monitor HTTP** on the Add Server page.
3. Enter the Monitor URL and its password. A self-signed certificate is shown on the first connection; compare its SHA-256 and trust it, or review it beforehand under **Monitor Certificate**.
4. Save the configuration.

SSH and Monitor HTTP can be enabled together. When both are configured, **Preferred transport** only controls which connection the App tries first; the other remains available. A server configured only through Monitor HTTP has no SSH credentials, and its command, terminal, and file features reach what the system account running the Monitor can reach.

## Step 2: Connect and view status

1. Tap the server card.
2. After connecting, view CPU, memory, swap, disk, and network status.

A server using the Monitor can show history collected before the App connected. An SSH-only server starts its local history when the App begins sampling.

## Step 3: Explore features

After connecting, you can:

- **Open the terminal**: SSH connections can open the terminal directly. Monitor HTTP connections open a shell as the account the Monitor runs as.
- **Browse files**: SSH connections use SFTP. Monitor HTTP connections use the Monitor's file API.
- **Manage containers**: View and control Docker or Podman containers.
- **View processes**: Inspect running processes.
- **Run snippets**: Execute saved commands.
- **Use Agent**: Diagnose or operate the server; see [Agent](/docs/advanced/agent/).

## Useful settings

- **Biometrics**: On mobile, enable Face ID, Touch ID, or fingerprint authentication to unlock the App quickly.
- **Home screen widgets**: After installing the Monitor, add the server to an iOS or Android widget.
- **Android background running**: To keep connections alive in the background, enable background running and allow notifications and background activity.
