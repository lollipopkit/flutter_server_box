Server Box は、iOS および Android デバイス向けにいくつかのモバイル特有の機能を提供しています。

## 生体認証

生体認証を使用してサーバーを保護します。

- **iOS**: Face ID または Touch ID
- **Android**: 指紋認証

設定 > セキュリティ > 生体認証 から有効にできます。

## ホーム画面ウィジェット

ホーム画面にサーバーの状態を表示するウィジェットを追加して、素早く監視できます。

### iOS

- ホーム画面を長押し
- **+** をタップしてウィジェットを追加
- 「Server Box」を検索
- ウィジェットのサイズを選択:
  - 小: 単一サーバーの状態
  - 中: 複数サーバーの状態
  - 大: 詳細情報

### Android

- ホーム画面を長押し
- **ウィジェット**をタップ
- 「Server Box」を見つける
- ウィジェットの種類を選択

## バックグラウンド実行

### Android

バックグラウンドで接続を維持します。

- 設定 > 詳細設定 > バックグラウンド実行 から有効にできます。
- バッテリーの最適化からの除外が必要です。
- アクティブな接続については常駐通知が表示されます。

### iOS

バックグラウンド制限が適用されます。

- バックグラウンドでは接続が一時停止する場合があります。
- アプリに戻った際に素早く再接続されます。
- バックグラウンド更新をサポートしています。

## プッシュ通知

サーバーの警告(オフライン、しきい値超過)は、サーバー上で動作する
[ServerBox Monitor](https://github.com/lollipopkit/flutter_server_box/tree/main/monitor)
から送信されます。警告ルールと通知チャネルは Monitor 側で設定します。

## モバイル UI の機能

- **プルリフレッシュ**: サーバー状態を更新
- **横向きモード**: より快適なターミナル体験
- **仮想キーボード**: ターミナル用ショートカット

## ファイル連携

- **ドキュメントピッカー**: SFTP アップロードやバックアップの入出力用にローカルファイルを選択
- **共有**: ファイルを他のアプリへエクスポート
