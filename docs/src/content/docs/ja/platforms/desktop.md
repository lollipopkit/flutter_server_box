---
title: デスクトップ版の機能
description: macOS、Linux、Windows 特有の機能
---

デスクトッププラットフォーム上の Server Box は、さらなる生産性向上機能を提供します。

## macOS

### ネイティブメニューバー

標準ショートカット付きのネイティブアプリメニュー:

- **Server Box**: このアプリについて、設定(⌘,)、終了(⌘Q)
- **ナビゲート**: ホームタブの切り替え
- **情報**: プロジェクト関連リンク

### ウィンドウ管理

- 起動をまたいでウィンドウサイズを記憶

## Linux

- X11 と Wayland をサポート
- ファイルピッカー統合
- AppImage で配布

## Windows

- ネイティブウィンドウコントロール
- ポータブル zip で配布

## クロスプラットフォームのデスクトップ機能

### テーマ

- ライトテーマ
- ダークテーマ
- AMOLED テーマ(純黒)
- システムテーマ(OS に追従)

### モバイル版に対する利点

- 監視に適した大画面
- ターミナル操作に適したフルキーボード
- より高速なファイル操作
- 優れたマルチタスク
