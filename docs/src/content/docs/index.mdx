## Main features

<CardGrid stagger>
	<Card title="Real-time monitoring" icon="chart">
		View live data and charts for CPU, memory, disks, network, GPU, and temperature.
	</Card>
	<Card title="SSH terminal" icon="terminal">
		Manage servers through a full-featured SSH terminal with multiple tabs and a virtual keyboard on mobile.
	</Card>
	<Card title="SFTP file browser" icon="folder">
		Manage server files with the built-in SFTP client and local file browser.
	</Card>
	<Card title="Container management" icon="box">
		Start, stop, and monitor Docker or Podman containers from the app.
	</Card>
	<Card title="Cross-platform" icon="device-mobile">
		Available on iOS, Android, macOS, Linux, Windows, and watchOS.
	</Card>
	<Card title="Multiple languages" icon="globe">
		Available with localized interfaces in multiple languages.
	</Card>
</CardGrid>
