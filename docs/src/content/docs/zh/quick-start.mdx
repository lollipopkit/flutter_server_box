---
title: 快速开始
description: 在几分钟内开始使用 Server Box
---

按照本指南连接第一台服务器并开始监控。

## 第一步：添加服务器

1. 打开 Server Box
2. 点击 **+** 按钮添加新服务器
3. 填写服务器信息：
   - **名称 (Name)**：服务器的友好名称
   - **主机 (Host)**：IP 地址或域名
   - **端口 (Port)**：SSH 端口（默认：22）
   - **用户 (User)**：SSH 用户名
   - **密码或密钥 (Password or Key)**：身份验证方式

4. 点击 **保存 (Save)** 添加服务器

### 通过 monitor agent 添加服务器

表单顶部的 **SSH / Monitor HTTP** 选择器决定连接方式。选择 **Monitor HTTP** 后，SSH 字段会被替换为 agent 的字段：

- **URL**：例如 `https://1.2.3.4:3770`
- **Monitor User** / **Monitor Password**：agent 的面板登录凭据
- **Monitor Ignore certificate**：用于自签名证书

以这种方式添加的服务器不携带任何 SSH 凭据。状态和图表无需额外配置即可使用。命令、终端和文件浏览取决于 agent 运维方启用的功能，详见 [Monitor Agent](/docs/zh/advanced/monitor-agent/)。此类服务器不提供 SFTP 和端口转发，需要这两项功能时请以 SSH 方式添加。

## 第二步：连接并监控

1. 点击服务器卡片进行连接
2. 您将看到以下内容的实时状态：
   - CPU 使用率
   - 内存 (RAM) 和交换分区 (Swap)
   - 磁盘使用情况
   - 网络速度

## 第三步：探索功能

连接后可以：

- **打开终端**：点击终端按钮打开 SSH 终端
- **浏览文件**：使用 SFTP 管理文件
- **管理容器**：查看和控制 Docker/Podman 容器
- **查看进程**：检查正在运行的进程
- **运行片段**：执行保存的命令
- **使用 Agent**：诊断或操作该服务器，见 [Agent](/docs/zh/advanced/agent/)

## 提示

- **生物识别身份验证**：启用 Face ID / Touch ID / 指纹以快速访问（移动端）
- **主屏幕小组件**：将服务器状态小组件添加到您的主屏幕（iOS/Android）
- **后台运行**：在后台保持连接（Android）
