description: 下载并安装 Server Box
---

Server Box 支持多个平台。请根据你的设备选择对应的下载来源。

## 移动端

### iOS

从 **[App Store](https://apps.apple.com/app/id1586449703)** 下载。

### Android

你可以从以下来源选择安装包：

- **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)**：项目发布页
- **[CDN](https://cdn.lpkt.cn/serverbox/pkg/?sort=time&order=desc&layout=grid)**：直接下载发布文件
- **[F-Droid](https://f-droid.org/packages/tech.lolli.toolbox)**：FOSS 应用商店
- **[OpenAPK](https://www.openapk.net/serverbox/tech.lolli.toolbox/)**：第三方应用商店

## 桌面端

### macOS

从 **[App Store](https://apps.apple.com/app/id1586449703)** 下载，或使用 Homebrew Cask：

```sh
brew install --cask server-box
```

macOS 版本支持 Intel 和 Apple Silicon。DMG 版本还提供本机终端功能；App Store 版本受沙盒限制，无法提供该功能。

### Linux

从 **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)** 或 **[CDN](https://cdn.lpkt.cn/serverbox/pkg/?sort=time&order=desc&layout=grid)** 下载 AppImage。

### Windows

从 **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)** 或 **[CDN](https://cdn.lpkt.cn/serverbox/pkg/?sort=time&order=desc&layout=grid)** 下载 zip 包。

## watchOS

Watch App 随 iOS App 一起通过 **[App Store](https://apps.apple.com/app/id1586449703)** 提供。安装后，在 iPhone App 中配置要显示的服务器。Watch App 需要 watchOS 10 或更高版本，iOS App 本身仍支持 iOS 15 或更高版本。

## 从源码构建

如果要从源码构建 Server Box，请参阅开发文档中的[构建指南](/docs/zh/development/building/)。

## 版本信息

前往 [GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases) 查看最新版本和变更日志。
