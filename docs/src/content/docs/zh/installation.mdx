Server Box 支持多个平台。请根据你的设备选择对应的下载来源。

## 移动端

### iOS

从 **[App Store](https://apps.apple.com/app/id1586449703)** 下载。

### Android

你可以从以下来源选择安装包：

- **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)**：项目发布页
- **[F-Droid](https://f-droid.org/packages/tech.lolli.toolbox)**：FOSS 应用商店
- **[OpenAPK](https://www.openapk.net/serverbox/tech.lolli.toolbox/)**：第三方应用商店

## 桌面端

### macOS

从 **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)** 下载，或使用 Homebrew Cask：

```sh
brew install --cask server-box
```

要求 macOS 13 或更高版本。GitHub Releases 分别提供适用于 Apple silicon 的 `ServerBox-<版本>-arm64.dmg` 和适用于 Intel 的 `ServerBox-<版本>-amd64.dmg`；Homebrew 会自动为当前 Mac 选择正确的版本。

Mac App Store 版本已不再更新。直接安装 DMG 版本即可，首次启动时会导入 App Store 版本的数据。

### Linux

从 **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)** 下载 `x86_64` 安装包：

- **Debian / Ubuntu（`.deb`）**：

  ```sh
  sudo apt install ./ServerBox_v1.0.N_amd64.deb
  ```

- **Fedora / RHEL / openSUSE（`.rpm`）**：

  ```sh
  sudo dnf install ./ServerBox_v1.0.N_x86_64.rpm
  # openSUSE：
  sudo zypper install ./ServerBox_v1.0.N_x86_64.rpm
  ```

- **AppImage（`.AppImage`）**：下载 `ServerBox_v1.0.N_amd64.AppImage`（Ubuntu 22.04 / Debian 12 等较旧 glibc 系统可选 `_legacy_amd64.AppImage`），赋予可执行权限后运行。
- **便携压缩包（`.tar.gz`）**：解压 `ServerBox_v1.0.N_linux_amd64.tar.gz` 后运行 `ServerBox_v1.0.N_linux_amd64/bundle/ServerBox`。

`.deb` 与 `.rpm` 安装包会将程序安装到 `/opt/serverbox`，创建 `/usr/bin/serverbox` 符号链接，并注册桌面入口与图标；基于 glibc 2.35 构建，兼容 Ubuntu 22.04+、Debian 12+、Fedora 与 openSUSE。

### Windows

从 **[GitHub Releases](https://github.com/lollipopkit/flutter_server_box/releases)** 下载安装程序（`ServerBox_v1.0.N_windows_amd64.exe`），或使用 WinGet / Scoop 安装：

```sh
winget install lollipopkit.serverbox
```

```sh
scoop bucket add extras
scoop install extras/serverbox
```

安装程序会为当前用户安装到 `%LOCALAPPDATA%\Programs\ServerBox`，不需要管理员权限，并添加开始菜单项和卸载程序。新版本会直接覆盖安装旧版本，设置和服务器数据会保留。

安装程序没有代码签名，SmartScreen 可能提示"未知发布者"。便携版 zip 也会随版本一并发布（同时作为官方 Scoop `extras` 桶的安装源）。

## watchOS

Watch App 随 iOS App 一起通过 **[App Store](https://apps.apple.com/app/id1586449703)** 提供。安装后，在 iPhone App 中配置要显示的服务器。Watch App 需要 watchOS 10 或更高版本，iOS App 本身仍支持 iOS 15 或更高版本。
