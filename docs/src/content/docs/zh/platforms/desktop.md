---
title: 桌面端功能
description: macOS, Linux 和 Windows 的平台特定功能
---

Server Box 提供桌面端专属功能。

## macOS

### 原生菜单栏

macOS 菜单栏提供以下菜单和快捷键：

- **Server Box**：关于、设置（⌘,）、退出（⌘Q）
- **导航**：切换首页标签页（⌘1 … ⌘9）
- **信息**：项目相关链接

### 窗口管理

- 记住窗口大小和位置，并在下次启动时恢复

## Linux

- 支持 X11 和 Wayland
- 文件选择器集成
- 以 AppImage 分发

## Windows

- 原生窗口控制
- 以便携 zip 包分发

## 跨平台桌面功能

### 主题

- 浅色模式
- 深色模式
- AMOLED 模式（纯黑）
- 自动 AMOLED（跟随系统，深色时使用 AMOLED）
- 系统模式（跟随系统设置）

### 与移动端相比

- 更多屏幕空间用于监控
- 全尺寸键盘更适合终端操作
- 更快的文件操作
- 更便于多任务处理
