Server Box 提供多项 iOS 和 Android 专属功能。

## 生物识别身份验证

使用设备的生物识别功能解锁应用：

- **iOS**：Face ID 或 Touch ID
- **Android**：指纹识别

在 设置 → **应用** → 设置 → **生物识别身份验证** 中启用。设备上没有录入任何生物
特征时，该项会直接说明，而不是给出一个无法生效的开关。

## 主屏幕小组件

在主屏幕添加服务器状态小组件，快速查看服务器状态。

### iOS

- 长按主屏幕
- 点击 **+** 添加小组件
- 搜索 “Server Box”
- 选择小组件尺寸：
  - 小号：单个服务器状态
  - 中号：多个服务器
  - 大号：详细信息

### Android

- 长按主屏幕
- 点击**小组件**
- 找到 “Server Box”
- 选择小组件类型

## 后台运行

### Android

在后台保持连接活跃：

- 在 设置 → **应用** → 设置 → **Android 设置** → **后台运行** 中启用
- 需要排除电池优化
- 活动连接将显示持久通知

### iOS

iOS 受后台运行限制：

- 后台连接可能会暂停
- 返回应用时快速重连
- 支持后台刷新

## 推送通知

服务器告警（离线、超过阈值）由运行在服务器上的
[monitor agent](/docs/zh/advanced/monitor-agent/)
推送。告警规则和推送渠道在 Monitor 侧配置。

## 移动端 UI 特性

- **下拉刷新**：更新服务器状态
- **横屏模式**：改善终端使用体验
- **虚拟键盘**：提供终端常用的快捷键

## 文件集成

- **文档选择器**：选择本地文件用于 SFTP 上传和备份导入/导出
- **分享**：将文件导出到其他应用
