title: 隐私政策
description: Server Box 保存什么、发送什么，以及如何关闭发送
---

Server Box 直接连接你的服务器。没有账号，没有代理连接的后端，开发者也没有运行任何能看到你管理了哪些机器的服务。

唯一的例外是诊断数据，下文说明，并且可以完全关闭。

最后更新：2026-08-29。

## 不会离开设备的数据

| 数据 | 保存位置 |
|---|---|
| 服务器地址、端口、用户名 | 设备上的加密 SQLite 数据库 |
| 密码和私钥 | 加密 SQLite 数据库；加密密钥保存在系统钥匙串中 |
| 备份密码 | 系统钥匙串 |
| 终端输出、命令输出、文件内容 | 不在会话之外保存，也不会上传 |
| SFTP 传输 | 仅在你的设备与你的服务器之间 |

备份只在你主动创建时生成，发送到你指定的位置。备份用你设置的备份密码加密。

## 诊断数据

这是 Server Box 唯一会发给开发者的数据，且只按你选择的级别发送。该选择在任何数据发送之前由引导页提出，之后可以随时在 **设置 → 诊断数据** 中更改。

| 级别 | 发送内容 |
|---|---|
| **不发送** | 什么都不发送。报告只留在设备上 |
| **基本信息** | 崩溃和被捕获的错误，以及发生时的 App 版本 |
| **完整信息** | 基本信息的全部内容，外加 App 运行期间的性能追踪 |

Android 上的默认值是**不发送**。iOS、macOS、Linux 和 Windows 上的默认值是**基本信息**，并且在第一次上传之前会显示引导页。

把级别改为**不发送**会立即停止发送，而不是在下次启动时生效。

### 一份报告包含什么

- 错误本身、错误信息和调用栈
- App 构建号、该构建是否包含 Linux userland、存储 schema 版本
- 操作系统名称、版本和内核版本；CPU 核心数；总内存；App 的内存占用
- 语言、地区和时区
- Dart 与 Flutter 运行时版本
- 诊断服务器为该安装生成的一个标识符

在**完整信息**级别下，还包含连接服务器、列出目录等操作的耗时——只记录耗时多久，不记录内容。

App 自身的日志**在任何级别下都不会上传**。它是写给开发者在设备上阅读的，其中一些是多年前的代码写下的，会把服务器名称直接拼进消息文本。日志只留在设备上：日志页面会展示它，下文的手动报告也会引用它。

### 一份报告不包含什么

- 你的主机名、IP 地址、姓名、邮箱地址或任何账号标识
- 任何广告标识符
- 密码、私钥或任何文件的内容
- 终端输出或任何命令的输出
- 真实的服务器名称、地址或用户名 —— 见下

### 脱敏

服务器名称、地址和用户名在记录该行日志时就被替换为占位符，而不是在发送时替换。报告说明的是"连接某台内网服务器失败"，而不是哪一台。

这不等于声称下文的手动报告是匿名的。旧版本 App 写下的日志行可能在消息文本里包含服务器名称，因此该报告会把完整文本展示出来，供你在发布前阅读。上传的报告则完全不含日志行。

## 手动报告崩溃

崩溃之后，Server Box 会提示报告。这条路径本身不发送任何数据：报告被复制到剪贴板，同时打开 GitHub issue 页面。由你粘贴，你会先看到自己将要发布的内容。它在所有诊断级别下都可用，包括**不发送**，也不需要在开发者处注册账号。

你发布到 GitHub 的内容是公开的，适用 [GitHub 的隐私声明](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement)。

## 诊断数据发往哪里

发往开发者自建的 Sentry 兼容服务器 `sentry.lollipopkit.com`。它不是第三方分析产品，数据不与任何人共享，也不用于广告、用户画像或跨 App、跨网站追踪。

报告只保留到足以定位它所描述的问题为止。如需删除来自你这台设备的报告，请带上 **设置 → 诊断数据** 中显示的标识符，在 [GitHub](https://github.com/lollipopkit/flutter_server_box/issues) 上提 issue。

## 其他网络请求

以下请求都是为了你使用的某项功能而发出的，都不携带诊断数据。

| 请求 | 目标 | 时机 |
|---|---|---|
| 检查更新 | `api.github.com` | 启动时，如果开启了自动检查更新 |
| Linux userland 镜像及其 manifest | `github.com` | 安装或更新本机 Linux 环境时 |
| 服务器 logo 图片 | 你配置的 URL | 设置了自定义 logo URL 时 |
| 文档和 issue 链接 | `serverbox.lollipopkit.com`、`github.com` | 你点击时 |

到你自己的服务器、以及到你部署的 Monitor agent 的连接，只发往那些机器。

## 手表 App 与桌面小组件

手表 App、它的复杂功能，以及 iOS 和 Android 的桌面小组件，都直接读取你部署的 Monitor agent。它们使用 App 为其签发的只读凭据，作用范围限于三个 metrics 接口。该凭据保存在手表自己的钥匙串中，在 iOS 上保存在共享钥匙串组中，在 Android 上用 AndroidKeyStore 密钥加密保存。

可以在**设置**中单独排除某台服务器，这会立即吊销该服务器的凭据。

## 应用商店

App Store 和 Google Play 版本还受商店自身的上报机制约束。Apple 的崩溃报告和 Google Play 的崩溃报告由平台收集，不由本 App 收集，适用 Apple 和 Google 各自的隐私政策。F-Droid 版本没有这类渠道，这也是 Android 默认值为**不发送**的原因。

## 儿童

Server Box 是管理服务器的工具，不面向儿童，也不收集任何能识别儿童身份的信息。

## 变更

收集内容发生实质变更时，诊断数据的询问会被重置，引导页会再次显示，而不是把旧的回答当作对新方案的同意。
