最后更新：2026-10-05。

Server Box 是连接你所配置服务器的客户端。它没有用户账号，开发者也不运营任何中转 SSH、SFTP 或 Monitor 流量的服务。连接时，流量会从 App 直接发往你设置的地址。

App 还会为诊断和你使用的功能发起独立的网络请求。下文会说明这些请求的目标和内容。Server Box 不包含广告，不使用广告标识符，也不会跨 App 追踪。

## 保存在本设备上的数据

| 数据 | 保存方式和行为 |
|---|---|
| 服务器名称、地址、端口、用户名和设置 | 加密的 SQLite 数据库 |
| SSH 密码、私钥、Monitor 和 BMC 凭据、保存的 sudo 密码、私钥口令、AI 提供商的 API 密钥、MCP 请求头，以及 WebDAV 的设置（含密码） | 加密的 SQLite 数据库；数据库加密密钥保存在系统钥匙串中 |
| 备份密码和同步密钥 | 系统安全存储 |
| App 日志 | 仅保存在本机日志文件中；为便于排查问题，仅保留当前运行和上一次运行的日志 |
| Agent 对话、记忆笔记、AI 提供商与工具设置 | 本机加密数据库；对话中可能包含提示词、模型回复、命令输出、终端文本、文件内容和读取的网页 |
| 活动终端输出 | 仅保存在当前活动会话中，会话结束后不再保留 |
| 下载的城市级位置数据 | 仅在你确认下载后，以未加密文件保存在 App 数据目录中；详见[地球仪与位置数据](#地球仪与位置数据) |
| 服务器上报的公网网卡地址结果（包括“无公网地址”） | 保存在 App 加密数据库中，每台服务器一条。记录满 7 天后会在后续状态轮询中刷新。经纬度坐标不落盘，每次需要时从本地数据集实时计算 |

Agent 对话不会纳入备份，也不会随设备同步发送；除非你从对话历史中手动删除，否则对话仅保留在本机。**备份 → 同步内容** 中可以逐类选择同步的内容：设置、AI（提供商、工具设置、命令权限和记忆笔记）、sudo 密码与 API 密钥（含 MCP 请求头和 WebDAV 的设置）、私钥口令（仅在保存口令的设备上）、字体、图片和 Skills，以及性能测试结果。不过在使用 Agent 功能时，相关对话上下文仍会发送给你所配置的 AI 提供商，详见 [AI 请求](#ai-请求)。

备份仅在你主动触发或启用自动同步时生成。根据选项和格式，无论是否加密，备份都可能包含服务器设置及其 SSH 密码、私钥、代码片段、端口转发、远程桌面配置及其保存的密码、容器设置、连接历史、应用偏好设置和 AI 设置；保存的 sudo 密码、API 密钥、MCP 请求头、WebDAV 设置以及私钥口令只包含在加密备份中。Agent 对话、AI 提供商与 MCP 服务器的登录状态及设备本地状态均不包含在内。字体、图片、Skills 和性能测试结果通过 iCloud、WebDAV 和 LK Cloud 同步，不写入备份文件。

未设置备份密码时，本地导出文件不会加密；设置备份密码后，导出的文件会在写入或上传前加密为 [age](https://age-encryption.org) 口令模式文件，不借助 ServerBox，用 `age -d` 和备份密码即可打开。自动同步强制要求设置非空的备份密码。同步发送的内容由同步密钥加密；同步密钥以 `identity.age` 存放在同一位置，是唯一由备份密码加密的文件：用 `age -d` 和密码可打开密钥，再用 `age -d -i` 和密钥打开其余内容。备份密码打不开该密钥的设备不会向该位置同步，直到输入其他设备使用的密码。备份上传至 iCloud、WebDAV 或 LK Cloud 后，同时受对应服务端存储与访问策略约束。

## 自动诊断数据

自动诊断是 Server Box 发往开发者诊断服务的唯一遥测数据。首次自动上传前，引导页会先提示你选择；之后可随时在 **设置 → 应用 → 隐私** 中更改。

| 级别 | 自动发送的内容 |
|---|---|
| **不发送** | 不自动上传任何内容。本机日志仍保留在设备上，你可随时手动导出报告。 |
| **基本信息** | 已捕获的崩溃和未处理异常，以及构建信息、平台信息和必要的诊断上下文记录。App 正常运行时不会持续发送数据。 |

所有平台的默认值均为**不发送**。除非你在引导页或设置中主动选择**基本信息**，否则不会上传任何数据。

切换为**不发送**后会立即停止自动上报，无需重启应用。

早期版本曾提供**完整信息**级别（包含性能追踪与功能使用统计），现已移除。旧版本升级后会自动转为**基本信息**，并清除此前保存在本机的统计标识符。当前任何级别均不会采集或上传性能追踪与功能使用事件。

### 自动报告包含的内容

视平台和错误类型而定，自动报告可能包含：

- 错误类型、错误详情及调用栈
- 应用构建号、存储结构版本，以及当前构建是否包含内置 Linux 运行环境
- 操作系统与内核版本、设备型号、CPU 核心数、内存容量及应用内存占用（因平台而异）
- 界面语言、区域设置与时区
- Dart 与 Flutter 运行时版本
- 结构化诊断操作记录，如连接方式、终端或文件传输后端类型，以及对应操作的结果
- 平台提供的原生崩溃（native crash）、应用无响应（ANR）或主线程卡死（hang）原因及调用栈

这些记录使用固定的操作名称，与服务器相关的字段均经过泛化或脱敏处理，不会将终端输出、文件内容、密码或私钥写入诊断字段。无论选择哪个级别，应用都不会上传常规运行日志。

错误消息和调用栈来自底层库，可能包含非应用主动生成的文本，因此无法保证所有异常文本都不含服务器信息。请勿将自动诊断视为对所有异常文本的完全匿名化。

应用本身不注册原生崩溃信号处理器。当系统提供原生崩溃、ANR 或卡死记录时，Server Box 会在下次启动时读取。若已开启自动诊断，该记录会作为错误报告发送；否则将保留在本机，供生成手动报告时使用。

## 脱敏与手动崩溃报告

结构化诊断记录在生成时即完成脱敏转换，随后才交由上报组件处理。记录采用固定的操作名称，服务器名称、地址和用户名等信息均会替换为占位符。

手动报告包含更完整的诊断信息。应用崩溃后，Server Box 会结合上次运行留下的日志以及系统提供的原生崩溃或卡死记录生成报告。应用会自动替换可识别的服务器名称、SSH 主机地址、SSH 用户名和 Monitor 地址，但报告中仍可能残留无法自动识别的字段。

最新生成的报告保存在 **设置 → 应用 → 隐私 → 崩溃报告** 中（仅当存在报告时显示该入口）。你可以先查看完整内容，再选择复制、复制并打开 GitHub Issue 页面，或直接删除。应用不会自动发布手动报告。该入口在所有诊断级别（包括**不发送**）下均可用。

**任何级别都不会自动上传应用运行日志。** 在**基本信息**级别下，应用可能发送导致异常退出的错误及调用栈，并附带前文所述的构建与设备信息，但不包含日志原文。若错误发生在上报通道初始化之前，应用可能会在下次启动时补发。保存在本机的手动报告会一直保留，直到你手动删除或被后续崩溃的新报告覆盖。

由于历史日志、曾连接的主机信息及无法自动识别的内容仍可能出现在手动报告中，手动报告不保证完全匿名。提交至 GitHub 的内容将公开可见，并适用 [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement)。

## AI 请求

Agent 使用你在 **设置 → 应用 → AI → 提供商** 中配置的服务商（包括模型目录中的内置服务商与自定义接口地址）。仅当你主动发送 Agent 消息时，应用才会向当前对话模型所属的服务商发起请求。

视操作类型而定，请求可能包含你输入的提示词、选中的终端文本、近期对话记录、已配置的服务器名称，以及 Agent 执行任务所需的上下文。执行命令或文件操作后，其返回结果也可能随后续请求一并发送，以便模型继续处理。

命令输出和文件内容中可能包含密码、令牌或其他敏感信息。发送前请留意相关内容，并查阅所选服务商的隐私政策。

服务商的 API Key 保存在 App 的加密数据库中，仅发送给对应的服务商。为避免密钥明文传输，连接非本机的明文 `http://` 自定义服务商默认会被拒绝，除非你单独为该服务商开启明文许可。当 Agent 使用 **网页读取** 工具时，会由本机直接请求目标网页；你添加的 MCP 服务器则会收到对应的工具调用请求。从远程地址安装或更新技能（Skill）时，应用会通过 `https` 从你指定的来源（GitHub、GitLab 或对应网站）下载；从本地文件夹或 `.zip` 压缩包安装时仅在本地读取，不发起网络请求。技能以文件形式保存在本机，随字体和图片一起同步。MCP 服务器的请求头与登录令牌保存在 App 的加密数据库中，仅发送给目标 MCP 服务器，且除本机地址外均强制使用 `https`；请求头随 sudo 密码与 API 密钥同步，登录状态只保留在本机。Server Box 不会通过开发者服务器中转任何 AI 请求。

## 地球仪与位置数据

地球仪功能会将每台服务器标注在对应地理坐标上。Server Box 使用保存在本机的数据集解析位置，不会将服务器地址发送给第三方地理位置 API，也不会在每次查询时请求远程服务。若服务器使用域名配置，设备仍会通过系统 DNS 解析域名，行为与常规连接一致。

服务器坐标按以下优先级依次确定：

- 你在服务器编辑页 **更多 → 位置** 中手动填写的坐标。
- 服务器自身上报的公网 IP 地址（仅在应用通过内网地址连接时使用）。该地址取自常规 SSH 或 Monitor 状态轮询结果，并通过本地已下载的城市级数据集解析，不会额外执行外部命令或请求第三方公网 IP 查询接口。
- SSH 或 Monitor 连接所使用的目标地址，通过本地已下载的城市级数据集解析。

城市级数据集不随应用安装包附带，也不会自动下载。在地球仪视图或 **设置 → 服务器 → 通用 → 地球仪** 中点击 **下载** 后，应用会先获取一份小型清单文件（manifest），在确认弹窗中展示下载体积、安装后占用空间、数据源 URL 及许可署名。仅在你确认后，应用才会开始下载数据文件。目前下载体积约为 25 MB，解压安装后约占 52 MB（具体数值以弹窗显示为准）。数据集按月更新；点击 **更新** 会直接替换现有文件，点击 **删除** 则会移除数据集。位置数据由 [DB-IP](https://db-ip.com) 提供，遵循 CC BY 4.0 许可协议。

下载服务器会收到来自你当前网络的清单及数据文件请求（含常规 HTTP 请求可见的来源 IP 与请求时间）。数据集安装完成后，所有位置查询均直接读取本地文件，不会再向下载服务器发送查询请求，因此远程服务无法获知你查询了哪些服务器地址、查询次数或查询时间。

由数据集自动解析出的坐标不会持久化保存，每次需要时均从本地数据集实时计算；删除数据集后，自动解析的位置即不再显示。你在服务器设置中手动填写的坐标不依赖该数据集，删除后依然有效。

应用仅在本地缓存服务器最近一次上报的公网网卡地址结果（包括“未上报公网地址”状态）。该记录保存在本机加密数据库中，不纳入备份或同步；缓存满 7 天后，会随常规状态轮询自动刷新。

关闭 **地球仪** 开关会隐藏服务器页面的地球仪入口并停止位置解析，但不会自动删除已下载的数据集或已缓存的公网地址记录。如需清理数据文件，请在数据集设置项中点击 **删除**。删除服务器时，对应的公网地址缓存记录会一并清除。

在**基本信息**诊断级别下，错误报告可能附带脱敏的操作轨迹（如打开地球仪视图、各来源成功解析的服务器数量统计），但绝不包含具体坐标、IP 地址、服务器名称或所属国家。

## 其他网络请求

以下网络请求仅在你使用对应功能时发起，且不会附带前文所述的自动诊断数据：

| 请求类型 | 目标地址 | 触发时机与传输内容 |
|---|---|---|
| AI 请求 | 你配置的服务商接口 | 发送 Agent 消息时；详见 [AI 请求](#ai-请求) |
| 备份与同步 | iCloud 或自建 WebDAV | 上传、下载或同步备份时；传输上传的备份文件（可能已加密）。同步时传输由同步密钥加密的备份和增量变更，以及由备份密码加密的同步密钥 |
| 检查更新 | `api.github.com` | 开启自动检查更新后，在应用启动时发起 |
| Linux 环境清单 | `github.com` | 检查内置 Linux 运行环境更新时发起，获取版本元数据与签名 |
| Linux 环境镜像 | 经签名验证的清单所指定的镜像源 URL | 安装或更新内置 Linux 运行环境时发起；下载后会根据清单中的摘要校验文件完整性 |
| 城市级位置数据 | `ipgeo.lollipopkit.com`（失败时回退至 GitHub Releases） | 在地球仪或 **设置 → 服务器 → 通用 → 地球仪** 中点击 **下载** 或 **更新** 时发起。先获取清单文件，确认后下载数据包；后续查询均在本地完成。详见 [地球仪与位置数据](#地球仪与位置数据) |
| 服务器图标或发行版标识 | 你配置的自定义 URL | 配置自定义图标 URL 后发起，目标图片服务器会收到加载请求 |
| 赞助列表 | `cdn.lollipopkit.com` | 打开赞助页面时发起 |
| 文档与反馈链接 | `serverbox.lollipopkit.com` 或 `github.com` | 点击相关外部链接时打开 |

连接你的服务器、BMC 接口以及自建 Monitor 时，所有流量均直连你配置的目标地址，不经过开发者的任何服务器。

## 诊断数据接收端

错误报告会发送至开发者维护的 Sentry 兼容服务（`sentry.lollipopkit.com`）。应用不向任何第三方统计或分析平台发送数据。

上报地址直接定义在开源代码中，因此基于未修改源码编译的构建版本同样使用该地址（除非编译者自行修改）。即便如此，自动诊断依然默认关闭，须由用户主动开启后才会生效。

诊断数据绝不用于广告投放，不与任何第三方共享，也不用于跨应用或跨网站追踪。诊断服务仅在排查对应问题所需的期限内保留报告。如需申请删除已上报的数据，请在 [github.com/lollipopkit/flutter_server_box](https://github.com/lollipopkit/flutter_server_box/issues) 提交 Issue，并附上大致上报时间、应用版本号及问题简述。请勿在公开 Issue 中填写密码、密钥或其他敏感信息。

## Watch 应用与桌面小组件

Apple Watch 应用、表盘复杂功能（Complication）以及 iOS / Android 桌面小组件均直接请求你部署的 Monitor 服务。Server Box 会为每个展示端签发独立的只读凭据，仅允许调用 Monitor 指标读取接口（`/api/v1/status`、`/api/v1/metrics` 和 `/api/v1/metrics/history`），无法打开终端、执行命令或访问文件系统。

只读凭据在 Watch 端保存在手表独立钥匙串中，在 iOS 端保存在应用组共享钥匙串中，在 Android 端则使用 AndroidKeyStore 密钥加密存储。小组件的配置列表包含服务器名称与 Monitor 地址以便你选择目标主机，而访问凭据则单独存放在系统安全存储内。所有配置了 Monitor 的服务器默认均会同步给小组件；Watch 端可在应用**设置**中单独勾选要排除的服务器。只要主应用能连通目标 Monitor，移除或排除服务器时便会同步吊销对应的 Watch 或小组件凭据。

## 应用商店渠道说明

通过 App Store 和 Google Play 安装的版本还会遵循所属平台自身的崩溃与诊断机制。Apple 和 Google 会依据各自的隐私政策收集相关系统级信息，这部分数据独立于 Server Box 的诊断机制之外。详情请参阅 [Apple 隐私政策](https://www.apple.com/legal/privacy/) 与 [Google 隐私政策](https://policies.google.com/privacy)。F-Droid 渠道版本不包含任何应用商店附加的上报组件。

## 未成年人保护

Server Box 是一款面向系统管理员与开发者的服务器管理工具，不面向未成年人设计，也不会主动收集任何可用于识别未成年人身份的信息。

## 政策变更

若诊断数据的收集范围或方式发生实质性变更，应用会重新弹窗征求你的确认，此前授予的许可不会自动延续至变更后的方案。

## 联系方式

如有隐私相关疑问，请在 [github.com/lollipopkit/flutter_server_box](https://github.com/lollipopkit/flutter_server_box/issues) 提交 Issue。
