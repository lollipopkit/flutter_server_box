---
title: 自定义命令
description: 在服务器页面上显示自定义命令输出
---

添加你自己的 shell 命令，它们的输出会显示在服务器详情页上，随状态一起刷新。

## 存放位置

每条命令是**服务器上目录里的一个文件**（`~/.config/server_box/custom_cmds`），
该目录是唯一的存储位置。App 不会另存一份，打开编辑器时读取该目录，保存时写回。

这意味着：

- **编辑时服务器必须可达。** 编辑器会直接说明这一点，不会接受无法保存的修改。
- **同一套命令是共享的。** monitor agent 的网页面板编辑的是同一个目录，App 的状态
  脚本读的也是它。三处无需额外同步即可保持一致。

## 编辑

1. 打开服务器编辑页，选择 **自定义命令** → **编辑**
2. 添加、重命名、修改或拖动排序
3. 保存

每一条由名称和命令组成。名称就是服务器详情页上标注该输出的标签。

**顺序会被保存，并用于决定状态页中的显示顺序。** 因此编辑器使用可拖拽列表。

## 特殊名称

### server_card_top_right

使用这个名称的命令不会与其他命令一起列出，它的输出显示在首页服务器卡片的右上角。

## 提示

**使用绝对路径：**

```sh
/usr/local/bin/my-script.sh
```

**支持管道：**

```sh
ps aux | sort -rk 3 | head -5
```

**格式化输出：**

```sh
uptime | awk -F'load average:' '{print $2}'
```

**保持执行时间短，最好控制在一秒以内。** 命令会在每次状态刷新时执行。

**限制输出量：**

```sh
tail -20 /var/log/syslog
```

## 安全性

命令使用 App 连接该服务器时的账号运行，即 SSH 用户或 monitor agent 所属的账号。
在 monitor 服务器上，编辑它们本身就需要 agent 的 `full_access`。该权限只有在 agent
启用终端能力，且请求满足安全传输或显式 `allow_insecure` 要求时才有效：往那个目录
加一个文件，等同于安排代码在每次刷新时执行。

避免使用会改变系统状态的命令。

## 从旧格式迁移

早期版本把这些存为服务器设置里的一个 JSON 对象。编辑该服务器的其他内容时，这些条目
会被原样带过，并在首次连接时移动到服务器上的目录。现在已经没有任何地方会写入旧位置。
