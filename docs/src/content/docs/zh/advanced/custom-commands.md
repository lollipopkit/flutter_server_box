---
title: 自定义命令
description: 在服务器详情页显示自定义命令的输出
---

你可以添加自定义 Shell 命令，并在服务器详情页查看命令输出。命令会随状态数据一起定期刷新。

## 存储位置

每条命令对应服务器上的一个文件，位于 `~/.config/server_box/custom_cmds`。这是唯一的存储位置：App 不会在本地另存命令，打开编辑器时从服务器读取，保存时直接写回服务器。

因此：

- **编辑时服务器必须可访问。** 服务器不可达时，编辑器会提示无法保存。
- **App 和 Monitor agent 共用同一组命令。** Monitor agent 网页面板编辑的也是这个目录，状态脚本也从这里读取，无需额外同步。

## 编辑命令

1. 打开服务器编辑页，选择 **自定义命令 → 编辑**。
2. 添加、重命名、修改或拖动命令。
3. 保存。

每条命令由名称和 Shell 命令组成。名称会作为服务器详情页中对应输出的标签。

**命令顺序会被保存，并决定状态页的显示顺序。** 因此编辑器使用可拖动列表。

## 特殊名称

### `server_card_top_right`

名称为 `server_card_top_right` 的命令不会与其他自定义命令一起显示，其输出会显示在首页服务器卡片的右上角。

## 编写建议

**使用绝对路径：**

```sh
/usr/local/bin/my-script.sh
```

**支持 Shell 管道：**

```sh
ps aux | sort -rk 3 | head -5
```

**格式化输出：**

```sh
uptime | awk -F'load average:' '{print $2}'
```

**控制执行时间：**最好在一秒内完成。命令会在每次状态刷新时执行。

**限制输出量：**

```sh
tail -20 /var/log/syslog
```

## 安全性

命令以 App 连接服务器时使用的身份运行：SSH 连接使用 SSH 用户，Monitor agent 连接使用运行 agent 的用户。

在 Monitor 服务器上，编辑自定义命令本身就需要 agent 的 `full_access` 权限。该权限要求 agent 已开启终端访问，并且请求通过安全传输，或明确配置了 `allow_insecure`。向该目录添加文件，等同于安排代码以 agent 用户身份在每次刷新时执行。

避免使用会修改系统状态的命令。不要在命令中写入密码、token 或其他凭据。

## 从旧格式迁移

早期版本将自定义命令保存为服务器设置中的 JSON 对象。编辑服务器其他配置时，App 会暂时保留这些条目，并在首次连接时将其迁移到服务器上的目录。当前版本不会再写入旧格式。
