---
title: 工作区
description: 同时查看多台服务器的多个界面，并使用快捷键操作
---

**工作区**标签页可以并排显示多个服务器界面。例如，把一台服务器的终端和状态页并排放置，或在一台服务器的 shell 下方显示另一台服务器的容器。区块中可打开服务器详情页里的各类界面。

新安装时这个标签页不在导航栏中：可以从**更多**打开，或者在**设置 › 应用 › 主页标签**中添加。

## 工作区、区块和标签

- **工作区**是一个命名的布局。可以保存多个，点按左上角的名称切换。
- 工作区由**区块**组成。区块可以向右或向下分屏；拖动两个区块之间的分隔线调整大小，双击分隔线恢复均分。
- 每个区块包含若干**标签**。一个标签是一台服务器的一个界面：终端、状态、文件、Agent、容器、进程、服务或代码片段。

把标签拖到另一个区块的边缘会分出新区块，拖到中间会并入该区块。在 iOS 和 Android 上，先长按标签再拖动。在手机上，或区块太窄而无法显示标签时，请拖动区块标题栏。

窄窗口同时显示两个区块：当前焦点区块，以及此前最近聚焦过的区块。顶栏的区块列表按钮列出全部区块，并可切换焦点。

**最大化**让一个区块占满工作区，其余区块隐藏，直到还原。双击区块的标签栏效果相同。窄窗口最多只显示两个区块，没有最大化。

关闭标签或区块后，可点提示中的撤销，也可按**重新打开关闭的标签**快捷键。撤销会恢复关闭前的工作区状态，关闭后对布局所做的改动也会丢失。关闭整个工作区或删除其中的服务器后，这条撤销记录也会失效。

## 重启之后

工作区保存在本机。App 重新启动后，设置为启动时自动连接的服务器，其标签在显示时自动重新连接。其他服务器的标签会等待点按**连接**，或等待这台服务器在服务器标签页中连接；两种方式都会连接这台服务器的全部标签。已删除服务器的标签会被移除。

## 同步输入

**同步输入**会把你在一个终端中按下的按键发送到工作区内的其他终端，类似 tmux 的 `synchronize-panes`。启用后，每个终端上方都会显示提示条。终端自动发出的应答（例如光标位置报告）不会转发。

## 模板

**把当前布局保存为模板**只保存区块布局和界面类型，不保存服务器配置。选择模板会按该布局新建工作区，并让所有标签使用焦点区块当前标签对应的服务器。焦点区块为空时，需手动选择服务器。

## 把终端移到工作区

在**终端**标签页中，选择**移到工作区**可将当前服务器终端移入工作区。本机终端不提供此操作。移动后，连接、shell 和屏幕内容都会保留。

## 快捷键

**设置 › 应用 › 快捷键**列出 App 的快捷键。可修改或移除可配置的快捷键；固定快捷键会列出，但不能修改。工作区快捷键只在工作区中生效；全局快捷键（例如打开设置）在各页面都生效。在工作区以外的终端中，工作区、设置页和服务器标签页对应的快捷键会传给 shell，因为这些操作在该终端中不可用。终端的复制、粘贴和全选操作不属于可配置快捷键。

| 命令 | Windows / Linux | macOS |
| --- | --- | --- |
| 快速打开 | `Ctrl+Alt+P` | `⌃⌘P` |
| 向右分屏 | `Ctrl+Alt+\` | `⌃⌘\` |
| 向下分屏 | `Ctrl+Alt+-` | `⌃⌘-` |
| 在区块之间移动焦点 | `Ctrl+Alt+←↑→↓` | `⌃⌘←↑→↓` |
| 新标签 | `Ctrl+Alt+N` | `⌃⌘N` |
| 关闭标签 | `Ctrl+Alt+W` | `⌃⌘W` |
| 下一个 / 上一个标签 | `Ctrl+Alt+]` / `Ctrl+Alt+[` | `⌃⌘]` / `⌃⌘[` |
| 当前区块的标签列表 | `Ctrl+Alt+O` | `⌃⌘O` |
| 重新打开关闭的标签 | `Ctrl+Alt+Shift+T` | `⌃⌘⇧T` |
| 最大化或还原区块 | `Ctrl+Alt+M` | `⌃⌘M` |
| 同步输入 | `Ctrl+Alt+I` | `⌃⌘I` |
| 切换工作区 | `Ctrl+Alt+S` | `⌃⌘S` |

在 Windows 和 Linux 上，同时包含 Control 和 Alt 的组合只响应左侧 Alt 键。右侧 Alt 键（AltGr）在许多键盘布局中用于输入 `\`、`[` 等字符，因此交给 shell 处理。
