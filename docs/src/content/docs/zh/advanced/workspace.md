---
title: 工作区
description: 同时查看多台服务器的多个界面，并使用快捷键操作
---

**工作区**标签页可以同时显示多个界面，例如同一台服务器的终端和状态并排，或者应用服务器的 shell 下方显示数据库服务器的容器。每个界面都是服务器详情页里打开的同一个页面，显示在区块中。

新安装时这个标签页不在导航栏中：可以从**更多**打开，或者在**设置 › 应用 › 主页标签**中添加。

## 工作区、区块和标签

- **工作区**是一个命名的布局。可以保存多个，点按左上角的名称切换。
- 工作区由**区块**组成。区块可以向右或向下分屏；拖动两个区块之间的分隔线调整大小，双击分隔线恢复均分。
- 每个区块包含若干**标签**。一个标签是一台服务器的一个界面：终端、状态、文件、Agent、容器、进程、服务或代码片段。

把标签拖到另一个区块的边缘会分出新区块，拖到中间会并入该区块。在 iOS 和 Android 上需要先长按再拖动；在手机上，或者区块窄到放不下标签栏时，拖动的是整条区块标题栏。

窄窗口同时显示两个区块：当前焦点区块和上一个焦点区块。顶栏的区块列表按钮列出全部区块，并可切换焦点。

**最大化**让一个区块占满工作区，其余区块隐藏，直到还原。双击区块的标签栏效果相同。窄窗口最多只显示两个区块，没有最大化。

关闭标签或区块后，可以在随后出现的提示中撤销，也可以使用**重新打开关闭的标签**快捷键。只能撤销最近一次关闭；撤销会把整个工作区恢复到关闭前的状态，之后对布局的改动也会一并撤回。删除在工作区中有标签的服务器后，无法再撤销。

## 重启之后

工作区保存在本机。App 重新启动后，设置为启动时自动连接的服务器，其标签在显示时自动重新连接。其他服务器的标签会等待点按**连接**，或等待这台服务器在服务器标签页中连接；两种方式都会连接这台服务器的全部标签。已删除服务器的标签会被移除。

## 同步输入

**同步输入**会把在一个终端中键入的内容逐键发送到本工作区的其他全部终端，效果与 tmux 的 `synchronize-panes` 相同。开启时每个终端上方会显示提示条。终端自动发出的应答（例如光标位置报告）不会被复制。

## 模板

**把当前布局保存为模板**会保存布局和每个区块的界面类型，不包含服务器。在工作区列表中选择模板会新建一个这种布局的工作区，全部标签使用焦点区块当前标签所在的服务器。工作区为空时需要选择服务器。

## 把终端移到工作区

在**终端**标签页中，**移到工作区**会把当前终端放入一个工作区。只有连接服务器的终端提供这个操作，本机终端没有。连接、shell 和屏幕内容都保持不变。

## 快捷键

**设置 › 应用 › 快捷键**列出 App 的组合键，可以逐个修改或移除。工作区中的终端不会把工作区的组合键和全局组合键（例如打开设置）发给 shell。在工作区以外，工作区的组合键会发给 shell，服务器标签页和设置页的组合键也一样。终端自带的复制、粘贴、全选按键不在这个列表中。

| 命令 | Windows / Linux | macOS |
| --- | --- | --- |
| 快速打开 | `Ctrl+Alt+P` | `⌃⌘P` |
| 向右分屏 | `Ctrl+Alt+\` | `⌃⌘\` |
| 向下分屏 | `Ctrl+Alt+-` | `⌃⌘-` |
| 在区块之间移动焦点 | `Ctrl+Alt+←↑→↓` | `⌃⌘←↑→↓` |
| 新标签 | `Ctrl+Alt+N` | `⌃⌘N` |
| 关闭标签 | `Ctrl+Alt+W` | `⌃⌘W` |
| 下一个 / 上一个标签 | `Ctrl+Alt+]` / `Ctrl+Alt+[` | `⌃⌘]` / `⌃⌘[` |
| 当前区块的标签列表 | `Ctrl+Alt+O` | `⌃⌘O` |
| 重新打开关闭的标签 | `Ctrl+Alt+Shift+T` | `⌃⌘⇧T` |
| 最大化或还原区块 | `Ctrl+Alt+M` | `⌃⌘M` |
| 同步输入 | `Ctrl+Alt+I` | `⌃⌘I` |
| 切换工作区 | `Ctrl+Alt+S` | `⌃⌘S` |

在 Windows 和 Linux 上，同时包含 Control 和 Alt 的组合只响应左侧 Alt 键。右侧 Alt 键（AltGr）在许多键盘布局中用于输入 `\`、`[` 等字符，因此交给 shell 处理。
