---
title: 工作区
description: 同时查看多台服务器的多个界面，并使用快捷键操作
---

**工作区**标签页可以同时显示多个界面，例如同一台服务器的终端和状态并排，或者应用服务器的 shell 下方显示数据库服务器的容器。每个界面都是服务器详情页里打开的同一个页面，显示在区块中。

## 工作区、区块和标签

- **工作区**是一个命名的布局。可以保存多个，点按左上角的名称切换。
- 工作区由**区块**组成。区块可以向右或向下分屏；拖动两个区块之间的分隔线调整大小，双击分隔线恢复均分。
- 每个区块包含若干**标签**。一个标签是一台服务器的一个界面：终端、状态、文件、Agent、容器、进程、服务或代码片段。

把标签拖到另一个区块的边缘会分出新区块，拖到中间会并入该区块。手机上长按区块标题栏后拖动。

窄窗口同时显示两个区块：当前焦点区块和上一个焦点区块。顶栏的区块列表按钮列出全部区块，并可切换焦点。

**最大化**让一个区块占满工作区，其余区块隐藏，直到还原。双击区块的标签栏效果相同。

关闭标签或区块后，可以在随后出现的提示中撤销，也可以使用**重新打开关闭的标签**。

## 重启之后

工作区保存在本机。App 重新启动后，各标签在点按**连接**之前不会建立连接；点按后，同一工作区中这台服务器的全部标签都会连接。已删除服务器的标签会被移除。

## 同步输入

**同步输入**会把在一个终端中键入的内容逐键发送到本工作区的其他全部终端，效果与 tmux 的 `synchronize-panes` 相同。开启时每个终端上方会显示提示条。终端自动发出的应答（例如光标位置报告）不会被复制。

## 模板

**把当前布局保存为模板**会保存布局和每个区块的界面类型，不包含服务器。在工作区列表中选择模板会新建一个这种布局的工作区，全部标签使用焦点区块所在的服务器。

## 把终端移到工作区

在**终端**标签页中，**移到工作区**会把当前终端放入一个工作区。连接、shell 和屏幕内容都保持不变。

## 快捷键

**设置 › App › 快捷键**列出 App 使用的全部组合键，可以逐个修改或移除。终端获得焦点时，这些组合由 App 处理，不会发给 shell；没有列出的组合照常发给 shell。

| 命令 | Windows / Linux | macOS |
| --- | --- | --- |
| 快速打开 | `Ctrl+Alt+P` | `⌃⌘P` |
| 向右分屏 | `Ctrl+Alt+\` | `⌃⌘\` |
| 向下分屏 | `Ctrl+Alt+-` | `⌃⌘-` |
| 在区块之间移动焦点 | `Ctrl+Alt+←↑→↓` | `⌃⌘←↑→↓` |
| 新标签 | `Ctrl+Alt+N` | `⌃⌘N` |
| 关闭标签 | `Ctrl+Alt+W` | `⌃⌘W` |
| 下一个 / 上一个标签 | `Ctrl+Alt+]` / `Ctrl+Alt+[` | `⌃⌘]` / `⌃⌘[` |
| 当前区块的标签列表 | `Ctrl+Alt+O` | `⌃⌘O` |
| 重新打开关闭的标签 | `Ctrl+Alt+Shift+T` | `⌃⌘⇧T` |
| 最大化或还原区块 | `Ctrl+Alt+M` | `⌃⌘M` |
| 同步输入 | `Ctrl+Alt+I` | `⌃⌘I` |
| 切换工作区 | `Ctrl+Alt+S` | `⌃⌘S` |

在 Windows 和 Linux 上，同时包含 Control 和 Alt 的组合只响应左侧 Alt 键。右侧 Alt 键（AltGr）在许多键盘布局中用于输入 `\`、`[` 等字符，因此交给 shell 处理。
