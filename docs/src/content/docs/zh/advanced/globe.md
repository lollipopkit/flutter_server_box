服务器页可以用交互式地球仪代替网格来显示服务器。点击服务器列表上方的地球图标即可切换视图；Server Box 会记住你上次使用的视图。

该功能默认开启。关闭 **设置 → 服务器 → 通用 → 地球仪** 后，服务器页会移除地球仪按钮，并停止位置解析。关闭功能不会删除已下载的城市级数据集；如需移除，请在 **城市级数据** 一行点击 **删除**。

## 如何确定服务器位置

Server Box 按以下优先级使用第一个可用的位置来源：

| 优先级 | 来源 | 使用条件 |
|---|---|---|
| 1 | 你填写的坐标 | 在服务器编辑页的 **更多 → 位置** 中设置 |
| 2 | 服务器上报的公网地址 | Server Box 通过内网地址连接时使用；仍需已下载的城市级数据集 |
| 3 | 连接服务器时使用的地址 | 需要已下载的城市级数据集 |

所有地理位置查询都使用本机文件，不会把服务器地址发送给地理位置 API。如果服务器配置使用域名，本设备仍可能通过系统配置的 DNS 服务解析域名，这与连接该服务器时的行为相同。

### 通过内网访问的服务器

通过 VPN 或内网域名访问的 VPS，仍可能在某个网卡上配置了公网 IP 地址。常规状态轮询已经会通过 SSH 或 [Monitor agent](/docs/zh/advanced/monitor-agent/) 上报这些网卡地址。Server Box 会从中选择公网地址，再使用本机城市级数据集查询位置；不会额外执行命令，也不会访问外部的公网 IP 查询服务。

位于 NAT 后方的家用服务器通常只能上报内网地址。这种情况下，只能通过手动填写坐标将它放到地球仪上。

## 下载城市级数据

城市级数据集不随 Server Box 附带，也不会自动下载。

1. 打开地球仪，在未定位服务器旁点击 **下载**。也可以打开 **设置 → 服务器 → 通用 → 地球仪**，在 **城市级数据** 一行点击 **下载**。
2. Server Box 会先获取一个很小的 manifest，用于显示当前下载大小、安装后占用、数据源 URL 和许可署名。
3. 阅读确认对话框。只有你确认后，App 才会下载数据文件。

当前数据集通常需要下载约 25 MB，安装后占用约 52 MB。确认对话框中的两个数字直接来自 manifest；如果估算值发生变化，应以对话框显示为准。

- IPv4 和 IPv6 数据均为城市级精度。
- 数据集每月更新。已有数据时，在设置中点击 **更新** 可检查新版本。
- 安装新版本会替换现有文件，不会额外保留一份副本。
- 点击 **删除** 可从设备中移除数据集。

下载服务可以看到你的网络请求了 manifest 或数据文件。安装完成后，每次位置查询都只读取本机文件；下载服务不会收到按次查询请求，因此无法知道你查询了哪些服务器地址或查询时间。完整数据流请参阅[隐私政策](/docs/zh/privacy/#地球仪与位置数据)。

没有城市级数据集时，只有手动填写了坐标的服务器能够显示在地球仪上。

## 没有坐标的服务器

无法定位的服务器会以 chip 的形式显示在地球仪底部。点击 chip 可打开对应服务器的编辑页并填写位置。

- **非公网地址**——Server Box 通过局域网、loopback、链路本地地址，或解析到这些地址的域名连接服务器。公共地理位置数据集无法定位这类地址。
- **无可用位置数据**——域名无法解析、已安装的数据集中没有匹配记录，或尚未安装城市级数据集。

如果所有未定位服务器的原因相同，chip 列表上方还会显示该原因。

## 手动填写位置

在服务器编辑页展开 **更多**，填写 **位置 (lat, lon)**。先输入纬度，再输入经度，单位为度，例如 `39.9042, 116.4074`。两个数字可以使用逗号或空白分隔。

纬度必须介于 -90 到 90，经度必须介于 -180 到 180。保存时，Server Box 会拒绝无效值，而不是静默丢弃。手动位置的优先级最高，不会被自动查询结果替换。

## 操作地球仪

- 拖动可旋转地球仪；快速滑动后会继续惯性转动。
- 双指手势可缩放；桌面端也支持鼠标滚轮和触控板手势。
- 当已定位的服务器位于背面时，地球仪会缓慢自动旋转。首次触碰后，本次视图中不再自动旋转。
- 服务器卡片会显示名称；读数到达后显示 CPU 和内存占用，连接期间显示连接状态。
- 标记颜色表示状态：读数可用时为绿色，连接中为橙色，连接失败后为红色，未连接时为灰色。
- 点击卡片或标记可打开服务器。
- 已定位服务器超过 14 台时，只持续显示标记，不再为每台服务器显示卡片。第一次点击标记会显示其卡片，再点一次才会打开服务器。

打开地球仪时，视角会朝向当前列表中第一台具有坐标的服务器。

## 位置不对时

坐标不会缓存。每次查询都使用设备上当前安装的数据集，因此安装新的月度版本后，地球仪会立即使用新结果，无需手动清理。

对于通过内网地址连接的服务器，Server Box 可能会记住该服务器上报的公网网卡地址。记录保存满 7 天后，后续的常规状态轮询可以重新采集。如需立即修正位置，请在服务器编辑页的 **更多 → 位置** 中手动填写坐标；手动坐标优先于所有自动来源。

实现细节请参阅[地球仪与位置解析](/docs/zh/principles/globe/)。
