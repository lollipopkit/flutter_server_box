服务器页提供网格和交互式地球仪两种视图。点击服务器列表上方的地球图标即可切换。再次打开服务器页时，Server Box 会沿用上次选择的视图。

地球仪默认开启。在 **设置 → 服务器 → 通用 → 地球仪** 中关闭后，地球仪按钮会隐藏，位置查询也会停止；已下载的城市级数据仍保留在设备上。若要同时删除数据，请在 **城市级数据** 一行点击 **删除**。

## 如何确定服务器位置

Server Box 会按以下顺序检查位置来源，并使用第一个可用的位置：

| 优先级 | 来源 | 使用条件 |
|---|---|---|
| 1 | 你填写的坐标 | 在服务器编辑页的 **更多 → 位置** 中设置 |
| 2 | 服务器上报的公网地址 | Server Box 通过内网地址连接时使用；仍需已下载的城市级数据集 |
| 3 | 连接服务器时使用的地址 | 需要已下载的城市级数据集 |

位置查询只读取本机数据集，不会把服务器地址发送给地理位置 API。若服务器配置的是域名，设备仍可能通过系统 DNS 服务解析它，和连接服务器时一样。

### 通过内网访问的服务器

通过 VPN 或内网域名访问的 VPS，某个网卡上仍可能配置公网 IP。常规状态轮询已经会通过 SSH 或 [Monitor](/docs/zh/advanced/monitor-agent/) 收集网卡地址。Server Box 会选取公网地址并查询本机城市级数据集，不会为此额外执行命令或访问外部 IP 查询服务。

位于 NAT 后方的家用服务器通常只能上报内网地址。这种情况下，只能通过手动填写坐标将它放到地球仪上。

## 下载城市级数据

Server Box 不附带城市级数据集，也不会自动下载。你可以按需安装：

1. 打开地球仪，在未定位服务器旁点击 **下载**；或前往 **设置 → 服务器 → 通用 → 地球仪**，在 **城市级数据** 一栏点击 **下载**。
2. Server Box 会先获取一份小型清单文件（manifest），用于展示下载体积、安装后占用空间、数据源 URL 及许可署名。
3. 核对确认弹窗中的信息，点击确认后才会开始下载数据文件。

目前下载体积约为 25 MB，安装后约占 52 MB（具体大小以确认弹窗从清单读取的最新数值为准）。

- IPv4 和 IPv6 均支持城市级定位精度。
- 数据集按月更新。安装后可在设置中点击 **更新** 检查新版本。
- 更新时会直接替换旧文件，不会保留多余副本。
- 点击 **删除** 即可从设备中移除数据集。

下载服务器会收到拉取清单与数据包时的常规网络请求；安装完成后的所有位置查询均直接读取本地文件，不会再向远程服务发起请求，因此下载服务器无法获知你查询的服务器地址或时间。详细数据说明请参阅[隐私政策](/docs/zh/privacy/#地球仪与位置数据)。

未安装城市级数据集时，地球仪上仅显示手动填写了坐标的服务器。

## 未定位的服务器

未能解析出坐标的服务器会以胶囊标签形式显示在地球仪底部，点击标签即可打开该服务器的编辑页并手动填写坐标。

- **非公网地址**：Server Box 通过局域网、本机回环（loopback）、链路本地地址，或解析为上述地址的域名连接服务器。公共地理位置数据库无法定位此类内网地址。
- **无可用位置数据**：域名解析失败、当前数据集中无匹配记录，或尚未安装城市级数据集。

若所有未定位服务器均出于同一原因，标签列表上方会统一显示该原因。

## 手动填写位置

在服务器编辑页展开 **更多**，填写 **位置 (lat, lon)**。按纬度、经度的顺序输入度数，例如 `39.9042, 116.4074`。两个值之间用逗号或空格分隔。

纬度必须介于 -90 到 90，经度必须介于 -180 到 180。保存时，Server Box 会拒绝无效值，而不是静默丢弃。手动位置的优先级最高，不会被自动查询结果替换。

## 操作地球仪

- 拖动可旋转地球仪；快速滑动后会继续惯性转动。
- 双指手势可缩放；桌面端也支持鼠标滚轮和触控板手势。
- 当已定位的服务器位于背面时，地球仪会缓慢自动旋转。首次触碰后，本次视图中不再自动旋转。
- 服务器卡片会显示名称；读数到达后显示 CPU 和内存占用，连接期间显示连接状态。
- 标记颜色表示状态：读数可用时为绿色，连接中为橙色，连接失败后为红色，未连接时为灰色。
- 点击卡片或标记可打开服务器。
- 已定位服务器超过 14 台时，只持续显示标记，不再为每台服务器显示卡片。第一次点击标记会显示其卡片，再点一次才会打开服务器。

打开地球仪时，视角会朝向当前列表中第一台具有坐标的服务器。

## 位置不对时

Server Box 不缓存查询结果。每次都会使用设备上当前安装的数据集，因此安装新的月度版本后，地球仪会立即显示新结果。

对于通过内网地址连接的服务器，Server Box 可能会记住该服务器上报的公网网卡地址。记录保存满 7 天后，后续的常规状态轮询可以重新采集。如需立即修正位置，请在服务器编辑页的 **更多 → 位置** 中手动填写坐标；手动坐标优先于所有自动来源。
