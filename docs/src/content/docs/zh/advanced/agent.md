---
title: Agent
description: 让模型诊断和操作你的服务器，每次一个经过确认的动作
---

Agent 将语言模型连接到你已配置的服务器。它每次提出一个操作，等待你确认。

在填入 API 端点和密钥之前，Agent 处于关闭状态。没有默认服务商，在此之前不会向任何地方发送内容。

## 两个入口

**Agent 标签页** 跨越你配置的所有服务器工作。它可以自己向不在列表里的主机建立 SSH
连接，也可以读取 ServerBox 自身的状态，来回答「哪些服务器掉线了」这类问题。

**SSH Agent** 位于终端页面，仅针对当前服务器。它能看到终端的上下文。选中一段
输出问它发生了什么，选中的内容会随问题一起发出。

Agent 标签页还可以浮动在其他标签页之上，这样一次诊断可以留在屏幕上，而你在终端或
文件浏览器里继续操作。设置 → **应用** → AI → **浮动在其他标签页上**。

## 配置

设置 → **应用** → **AI**：

| 配置项 | 默认值 |
|---|---|
| **API 端点** | `https://api.openai.com` |
| **模型** | `gpt-5.4-mini` |
| **API 密钥** | 空 |
| **协议** | 自动 |

端点可以填写服务的 base URL，也可以填写完整的 Chat Completions 或 Responses 端点。
App 会按所用协议补全路径。**自动** 对官方 OpenAI 端点使用 Responses，对兼容服务商
使用 Chat Completions，因此多数第三方网关无需改动即可工作。

任何支持这两种协议之一的服务商都可以用。密钥保存在设备上，与服务器密码使用同一个
加密存储。

## 它能做什么

| 工具 | 作用 |
|---|---|
| **Shell** | 执行一条完整的、非交互式的命令 |
| **读取文件** | 经 SFTP 读取文本文件 |
| **写入文件** | 经 SFTP 替换文本文件，需先确认 |
| **SSH 连接** | 向未配置的主机建立连接 |
| **断开 SSH** | 关闭其中一个连接 |
| **ServerBox** | 读取 App 自身的状态，包括有哪些服务器及其状态 |

## 确认与批准

模型提出的每个操作都会在执行前展示，包含命令以及模型对操作作用和风险的说明。你批准或拒绝。
拒绝会告知模型，它从那里继续。

**自动执行只读命令**（设置 → 应用 → AI）允许明确只读、幂等的命令无需提示直接执行。
它**默认关闭**，且只对服务器生效。

模型会把每个动作标记为安全或不安全，那个标记是决策的输入，不是决策本身。请阅读命令。

## 连接未配置的主机

Agent 可以建立临时 SSH 连接。需要密码时，App 会用对话框向你索取，**绝不在对话中**，
因为在对话里输入的任何内容都会随对话一起保存并发送给模型。

这类连接是临时的，单独列出。如果其中某个值得保留，可以存为服务器；主机和你输入的
密码此后就像其他服务器一样保存在设备上。

## 在本机执行命令

与上述全部无关，且**在你打开之前一直关闭**：设置 → 应用 → AI → **在本机执行命令**。

服务器是你有意添加的，而且在别处。本机是 App 自身数据、你的私钥和钥匙串所在的地方，
没有人会因为添加了一台服务器就默认同意让模型碰这些。所以它是独立的开关，而且
**这里的任何命令都不会无人值守地执行。** 无论看起来多么只读，也无论自动执行那个
设置是什么，每条命令都需要确认。

「本机」的含义取决于平台：

- **桌面端**：计算机本身，你的文件就在上面
- **Android 和 iOS**：ServerBox 安装的 Alpine Linux 容器，它看不到手机自身的
  文件系统、App 的数据或你的文件。见 [本机终端](/docs/zh/advanced/local-terminal/)

在无法提供该功能的平台上，这个开关不会出现。App Store 的沙盒 macOS 版本无法启动 shell，
不带 Linux 引擎的 iOS 版本同样如此。

## 历史记录

Agent 标签页的对话保存在设备上，可以重新打开。在对话历史界面可以全部清除。

## 需要知道的几点

- **模型可能出错。** App 在每个对话上都写明了这一点，确认这一步正是为此存在。
- **命令输出会发送给模型。** 这是它的工作方式。你在终端选中并提问的内容同样如此。
  请注意屏幕上有什么。
- **一次一个动作。** Agent 不会排好一整套计划然后执行；它提出、等待，并从结果继续。
- **默认回车发送。** Shift+回车换行。设置 → 应用 → AI → **回车发送** 可以对调。
