Agent 可将大语言模型连接到你的服务器。权限模式决定哪些操作无需询问即可执行（详见[操作审批](#操作审批)）。

发送第一条消息前，请先在 **设置 → 应用 → AI → 提供商** 中配置服务商：你可以选择内置服务商（如模型目录中的 OpenAI、Anthropic、Google 等）并填入 API Key，也可以添加自定义的 OpenAI 兼容、Anthropic 或 Google 接口地址。新对话默认使用的模型也在此页面选择。API Key 保存在应用的加密数据库中，且仅发送给所属的服务商。仅当你主动发送消息时，应用才会发起网络请求。

## 选择 Agent 入口

Server Box 提供两个 Agent 入口：

- **Agent 标签页**：可同时操作多台已配置的服务器，也可通过临时 SSH 连接访问列表外的主机，还能读取服务器列表、连接状态等应用内信息。
- **SSH Agent**：位于终端页面，仅作用于当前服务器。它可以读取当前终端屏幕内容，并在当前连接中执行命令。在终端选中文本后点击 **询问 AI**，会直接新建对话并将选中内容填入输入框。

两个入口各自维护独立的对话列表，终端内的对话归属于对应服务器。Agent 默认以浮动面板形式展示，切换到终端或文件管理器时仍可随时查看对话；点击 Agent 标题栏中的浮动按钮即可收起面板。

## 服务商与模型

**设置 → 应用 → AI → 提供商** 会列出所有内置服务商以及你添加的自定义服务商。添加自定义服务商时，需填写包含 API 版本路径的 Base URL（例如 `https://api.example.com/v1`），并选择接口协议：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 或 Google Generative AI。OpenAI 兼容接口会自动拉取可用模型列表；其他协议则需手动填写模型 ID。

为防止 API Key 明文传输，指向非本机的明文 `http://` 地址默认会被拒绝，除非你为该服务商单独开启 **允许明文 HTTP**（`http://localhost` 等本机回环地址无需开启）。

未在应用内填写 API Key 的内置服务商，会自动读取应用启动时对应的系统环境变量（变量名与官方工具一致，如 `OPENAI_API_KEY`、`ANTHROPIC_API_KEY`、`GEMINI_API_KEY`）。服务商列表会在 **系统** 分组下显示该项，并注明密钥来源变量；若在应用内填写了密钥，则优先使用应用内配置。

若环境中设置了 `OPENAI_BASE_URL`，列表会额外生成一个名为 **系统** 的服务商，指向该地址对应的 OpenAI 兼容接口，密钥取自 `OPENAI_API_KEY`，并可用 `OPENAI_MODEL` 补充接口未列出的模型。此时 `OPENAI_API_KEY` 仅发送给该自定义地址，内置 OpenAI 服务商不会将其发往 `api.openai.com`（除非该地址本身就是 OpenAI 官方地址）。环境变量配置不会持久化写入磁盘，每次均以应用启动时的环境为准。注意在 macOS 上，从访达或程序坞启动的应用不会加载终端 shell 配置文件中导出的环境变量。

旧版本中的 AI 配置（接口地址、模型、协议及密钥）在升级后会自动迁移为一条自定义服务商记录。

## Agent 工具能力

Agent 标签页提供以下工具：

| 工具 | 说明 |
|---|---|
| **Shell** | 在目标服务器上执行非交互式命令 |
| **读取文件** | 通过服务器配置的 SFTP 或 SCP 读取远程文本文件；开启本机执行后也可读取本机文件 |
| **写入文件** | 通过配置的传输协议写入或替换远程文本文件；开启本机执行后也可写入本机文件 |
| **SSH 连接** | 临时连接到未保存在服务器列表中的主机 |
| **断开 SSH** | 断开临时建立的 SSH 连接 |
| **Server Box** | 读取应用内状态，包括服务器列表与当前连接状态 |
| **记忆** | 在本机保存跨对话笔记，供后续对话读取 |
| **对话历史** | 搜索并读取过往的 Agent 对话记录 |
| **网页读取** | 从本机直接请求并读取网页内容 |
| **代码片段** | 查看、新增、修改或删除代码片段（修改前需确认，且不会将片段设为自动运行） |
| **虚拟化** | 读取虚拟化标签页中已加载的虚拟机与容器状态（不会主动连接尚未加载的宿主机） |
| **性能测试** | 查看测试结果、启动或停止测试（每次操作均需确认）。单次测试约需 10–20 分钟，完成后会通知原对话并由 Agent 解读结果 |
| **远程桌面** | 查看远程桌面配置、发起连接（在远程桌面标签页打开）或断开连接（操作前需确认；未保存密码的配置需在界面内手动连接） |

终端内的对话仅包含两个工具：在当前终端会话中执行的 **Shell**，以及 **读取屏幕**。你可以在 **设置 → 应用 → AI → 工具** 中按分类停用工具，或添加 MCP 服务器以扩展 Agent 标签页的可用工具。

点击已添加的 MCP 服务器即可编辑。需要鉴权的服务器（Streamable HTTP）可配置自定义请求头（例如名称填 `Authorization`，值填 `Bearer <token>`）。使用 OAuth 的服务器会显示 **需要登录**，点击 **登录** 后将在浏览器中完成授权，应用会自动保存并续期令牌。请求头随密码与密钥同步，登录状态只保留在本机；两者除本机地址外均强制通过 `https` 发送。

## 技能（Skills）

技能（Skill）是针对特定任务编写的一组操作指南，由 `SKILL.md` 及其同目录文件组成。你可以在 **设置 → 应用 → AI → 技能** 中安装技能，支持的来源格式与 `npx skills add` 一致：`owner/repo`、`owner/repo@skill`、GitHub 或 GitLab 仓库及子目录链接、指向 `SKILL.md` 或压缩包的直链，以及发布了 `/.well-known` 技能索引的网站；也可以直接粘贴完整的 `npx skills add …` 命令。此外还支持从本机文件夹或 `.zip` 压缩包安装。若来源中包含多个技能，可勾选需要安装的项。

模型初始仅加载每个技能的名称与简介，当任务匹配时才会按需读取完整内容（读取过程无需手动确认）。技能与工具相互独立：停用工具不会影响技能，每个技能也可单独启用或停用，终端内的 Agent 对话同样可以使用技能。由于模型会按照技能文档的指示操作，请仅从你信任的来源安装技能；技能包中附带的脚本不会自动执行。应用每天最多自动检查一次技能更新（在启动或打开技能页面时），并标记有更新的项；点击 **全部更新** 可安装更新，点击 **检查更新** 可立即手动检查，未经确认不会自动覆盖安装。

应用内置了 **serverbox-help** 技能，涵盖 Server Box 使用说明与 Monitor 部署指南，因此你可以直接向 Agent 咨询应用用法，或在批准后让 Agent 协助你在服务器上部署 Monitor。该内置技能随应用更新，可随时停用，但不可删除。

Agent 的文件读写工具依赖 SSH 连接；仅配置了 Monitor HTTP 的服务器不支持 Agent 文件工具（但仍可在独立的 **文件** 标签页中使用 Monitor 文件接口）。

## 操作审批

权限模式有 **手动**、**自动** 和 **全部放行**，可在输入框下方或 **设置 → 应用 → AI → 命令权限** 中切换，两处都对所有对话生效。该页面的规则和判断逻辑与 Monitor 的 [Agent 模式](/zh/docs/advanced/monitor-agent-mode/) 相同；Monitor 输入框中的切换同样会修改该服务器新任务的模式。

每个操作先经过命令规则：**拒绝**，然后 **询问**，然后 **允许**。之后：

- 无法撤销的操作需要询问，**全部放行** 除外。
- 其余按模式处理，只读操作和 MCP 工具也一样。**手动** 询问你；**自动** 由对话的模型按自动模式规则判断：允许就执行，拦截就把原因告诉 Agent，没有结论时询问你；**全部放行** 直接执行，拒绝和询问规则仍然生效，开启 **关闭全部放行** 后不能选这个模式。

询问时，应用会展示命令、风险等级和模型的说明。拒绝的结果会反馈给模型。在终端对话中，你也可以把命令插入终端，修改后自己执行。模型标注的风险等级仅供参考，请以实际命令内容为准。

## Agent 提问交互

当遇到需要你做决定或无法自行获取的信息时，Agent 会暂停并向你提问（每次最多 4 个问题）。每个问题会提供可单选或多选的选项（也可选择 **其他** 并手动输入），或直接请求文本输入。标题栏、对话列表及悬浮胶囊上的圆点代表对话正等待你回复，旋转图标则代表 Agent 正在处理。在等待回复期间直接发送新消息，会自动取消当前提问表单并将新消息发给 Agent。

若涉及密码、密钥或令牌，Agent 会使用专用的保密输入框。你填入的敏感内容不会发给语言模型，也不会写入对话历史：Agent 仅获得一个一次性引用句柄，在工具实际调用时由应用在本地替换为真实值（例如连接未保存密码的远程桌面配置）。

## 临时连接其他主机

Agent 可以临时通过 SSH 连接未添加至服务器列表的主机。若目标主机需要密码，应用会弹出独立对话框请求输入，请勿直接在聊天输入框中发送密码。临时连接会在列表中单独展示；如需长期保留，可将其保存为正式服务器，此后主机信息与凭据将按常规服务器加密保存。

## 在本机执行命令

**在本机执行命令** 是 **设置 → 应用 → AI** 中的独立开关，默认关闭。开启后，本机命令和其他命令一样按权限模式处理：**全部放行** 下会直接执行，不再询问。

本机命令的实际执行环境因平台而异：

- **桌面端**：直接在运行 Server Box 的宿主机系统中执行，可访问本机文件。
- **Android 与 iOS**：在应用内置的 Alpine Linux 隔离环境中执行，无法访问手机自身的文件系统、应用数据或个人文件。详见[本机终端](/docs/zh/advanced/local-terminal/)。

在不支持本机命令的平台上，该选项会自动隐藏（例如 macOS App Store 版本受系统沙盒限制无法启动外部 shell；不含 Linux 引擎的 iOS 构建版本同样无法执行本机命令）。

## 对话历史

对话记录保存在本机的加密数据库中，较长的对话会在增长过程中自动压缩上下文。你可以在历史列表中重新打开、重命名或删除对话。对话历史不纳入备份或同步。服务商配置、工具开关、命令权限及记忆笔记在 **备份 → 同步内容** 的 **AI** 下同步，API Key 在 **密码与密钥** 下同步。对话消息和工具返回结果中可能包含命令输出、文件内容及你粘贴的终端文本，在对话过程中这些内容会发送给所选的模型服务商。

## 使用前提示

- 语言模型可能生成错误的建议或命令，批准任何操作前请务必仔细核对。
- 命令输出、文件内容、终端文本及网页内容可能会发送给模型服务商进行分析，发送消息或批准工具调用前请确认其中不含敏感信息。
