---
title: Agent
description: 让模型诊断和操作服务器，并在每次操作前请求确认
---

Agent 会将语言模型连接到你已配置的服务器。模型每次提出一个操作，App 都会在执行前请求你的确认。

在配置 API endpoint 和 model 之前，Agent 处于关闭状态，不会向任何服务发送内容。只有需要身份验证的服务商才需要填写 API key；填写后，App 会将它作为 bearer token 发送。

## 两个入口

**Agent 标签页**可以访问你配置的多个服务器。它可以为未添加到列表的主机建立临时 SSH 连接，也可以读取 Server Box 的服务器状态，例如回答“哪些服务器离线了”。

**SSH Agent**位于终端页面，只针对当前服务器。它可以读取终端上下文；你选中终端输出后提交的问题，会连同选中内容一起发送给模型。

Agent 标签页还可以浮动在其他标签页上方。这样你可以在终端或文件浏览器中继续操作，同时保留诊断对话。入口位于 **设置 → 应用 → AI → 浮动在其他标签页上**。

## 配置

打开 **设置 → 应用 → AI**：

| 配置项 | 默认值 |
|---|---|
| **API endpoint** | `https://api.openai.com` |
| **Model** | `gpt-5.4-mini` |
| **API key** | 空 |
| **Protocol** | 自动 |

Endpoint 可以填写服务的 base URL，也可以填写完整的 Chat Completions 或 Responses endpoint。App 会根据所选协议补全路径。选择**自动**时，官方 OpenAI endpoint 使用 Responses，兼容服务使用 Chat Completions；大多数第三方 gateway 无需额外修改即可使用。

只要服务商支持其中一种协议，就可以配置使用。API key 保存在设备上，与服务器密码使用相同的加密存储。

## 可用工具

| 工具 | 作用 |
|---|---|
| **Shell** | 执行完整的非交互式命令 |
| **读取文件** | 通过 SFTP 读取 SSH 服务器上的文本文件；开启本机执行后，也可以读取本机文件 |
| **写入文件** | 通过 SFTP 替换 SSH 服务器上的文本文件；开启本机执行后，也可以替换本机文件，但每次都需要确认 |
| **SSH 连接** | 连接未在 App 中配置的主机 |
| **断开 SSH** | 关闭临时 SSH 连接 |
| **Server Box** | 读取 App 自身的状态，包括服务器列表和连接状态 |

## 确认和批准

模型提出的每个操作都会在执行前显示，包括命令以及模型对作用和风险的说明。你可以批准或拒绝。拒绝结果会返回给模型，模型可以据此继续对话。

**自动执行只读命令**位于 **设置 → 应用 → AI**。开启后，App 可以自动执行被明确判定为只读且幂等的服务器命令。此设置默认关闭，仅适用于服务器，不适用于本机命令。

模型会为每个操作标记安全或不安全。该标记只作为参考，不能代替你阅读命令并作出决定。

仅配置 Monitor HTTP 的服务器不提供 Agent 的 SFTP 文件工具，因为这些工具要求 SSH。该服务器的独立**文件**标签页可以在运维人员开启 `[remote_access.fs]` 且目标路径位于 `roots` 内时，使用 Monitor agent 的 `/api/v1/fs/*` 文件 API。

## 连接未配置的主机

Agent 可以建立临时 SSH 连接。需要密码时，App 会在单独的对话框中向你索取，**不会在 Agent 对话中要求输入**。在对话中输入的内容会随对话保存并发送给模型。

临时连接会单独列出。如果要长期使用，可以将它保存为服务器。保存后，主机信息和密码会像其他服务器凭据一样存储在设备上。

## 在本机执行命令

**在本机执行命令**与服务器操作相互独立，默认关闭。入口位于 **设置 → 应用 → AI → 在本机执行命令**。桌面端的本机执行目标是计算机本身；移动端的目标是 App 提供的 Alpine Linux 环境。

服务器是你主动添加的远程目标；本机则包含 App 数据、私钥和系统钥匙串，因此添加服务器不代表你同意模型访问本机。开启本机执行后，命令仍然**不会自动执行**：无论命令看起来是否只读，无论“自动执行只读命令”是否开启，每条本机命令都需要确认。

“本机”的含义取决于平台：

- **桌面端**：运行 Server Box 的计算机，可以访问该计算机上的文件
- **Android 和 iOS**：Server Box 提供的 Alpine Linux 容器，无法访问手机自身的文件系统、App 数据或用户文件。详见[本机终端](/docs/zh/advanced/local-terminal/)

无法提供本机执行能力的平台不会显示此开关。App Store 版 macOS 受沙盒限制，无法启动 shell；未包含 Linux engine 的 iOS 版本也无法提供该功能。

## 历史记录

Agent 标签页的对话会保存在设备上，可以在对话历史界面重新打开或全部清除。

## 注意事项

- **模型可能生成错误建议或命令。** 每个对话都会提示这一点，执行前确认是必要的安全步骤。
- **命令输出会发送给模型。** 这是模型分析服务器所必需的；终端中选中并提交的内容也会发送。提交前请确认输出中没有敏感信息。
- **Agent 一次只执行一个操作。** 它不会预先安排并自动执行完整计划，而是提出一个操作，等待结果后再继续。
- **默认按回车发送**；Shift+回车换行。可以在 **设置 → 应用 → AI → 回车发送** 中切换行为。
