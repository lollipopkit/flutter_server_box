---
title: Agent
description: 让模型诊断服务器，并在每次操作前由你审核
---

Agent 会将语言模型连接到你的服务器。模型每次提出一个操作，App 都会先展示操作内容，
由你决定是否执行。

Agent 提供默认的 API endpoint 和 model，无需配置即可使用。若要切换 provider，可在
**设置 → 应用 → AI** 中修改 endpoint、model、protocol 或 API key。只有要求身份验证的
provider 才需要 API key。配置后，App 会将 key 作为 bearer token 发送，并与服务器密码
一起保存在加密数据库中。只有发送消息时，App 才会向 provider 发起请求。

## 选择 Agent 入口

Server Box 提供两个 Agent 入口：

- **Agent 标签页**：可处理已配置的多个服务器，也可通过临时 SSH 连接访问服务器列表外的
  主机。它还能读取 App 状态，例如服务器列表和连接状态。
- **SSH Agent**：位于终端页面，只针对当前服务器。它可以读取终端上下文；如果你先选中
  一段终端输出再提问，这段文字也会随消息发送给模型。

Agent 标签页可以浮在其他标签页上方，方便你在终端或文件浏览器中操作时继续查看对话。
在 **设置 → 应用 → AI → 浮动在其他标签页上** 中开启此功能。

## 配置 provider

打开 **设置 → 应用 → AI** 配置 provider：

| 配置项 | 默认值 |
|---|---|
| **API endpoint** | `https://api.openai.com` |
| **Model** | `gpt-5.6-luna` |
| **API key** | 空 |
| **Protocol** | 自动 |

**API endpoint** 可以填写服务的 base URL，也可以填写完整的 Chat Completions 或
Responses endpoint。App 会根据所选 protocol 补全 endpoint 路径。选择**自动**时，官方
OpenAI endpoint 使用 Responses，兼容 provider 使用 Chat Completions。大多数第三方
gateway 无需额外调整 protocol；provider 只需支持其中一种协议即可。

## Agent 可以使用哪些工具

| 工具 | 作用 |
|---|---|
| **Shell** | 在服务器上执行完整的非交互式命令 |
| **读取文件** | 通过该服务器配置的 SFTP 或 SCP 读取 SSH 服务器上的文本文件；开启本机执行后也能读取本机文件 |
| **写入文件** | 通过已配置的传输方式替换文本文件；开启本机执行后也能替换本机文件。每次写入都需要确认。 |
| **SSH 连接** | 临时连接 App 中尚未配置的主机 |
| **断开 SSH** | 关闭临时 SSH 连接 |
| **Server Box** | 读取 App 自身状态，包括服务器列表和连接状态 |

Agent 的文件工具要求使用 SSH。仅配置 Monitor HTTP 的服务器不提供这些工具；该服务器
独立的**文件**标签页可使用 Monitor agent 的文件 API，但运维人员必须先启用
`[remote_access.fs]`，且访问路径必须位于 `roots` 指定的目录中。

## 审核操作

每个操作执行前，App 都会显示命令，以及模型对其作用和风险的说明。请先阅读命令，再决定
批准或拒绝。拒绝结果会返回给模型，供它继续回答。模型标注的“安全”或“不安全”仅供参考，
不能代替你审核命令。

在 **设置 → 应用 → AI** 中可开启**自动执行只读命令**。只有模型和 App 本地检查都将服务器
命令判定为只读，且该命令同时满足幂等、无破坏性时，App 才会跳过逐次确认。此选项默认关闭，
也不适用于本机命令。Agent 每次只处理一个操作，会等待操作结果后再提出下一步。

## 连接其他主机

Agent 可以通过临时 SSH 连接访问服务器列表外的主机。需要密码时，App 会在独立对话框中
询问；不要在 Agent 对话里输入密码。对话文本会保存在本机，并在发送消息时传给配置的
model。临时连接会单独列出。若要保留连接，可将主机保存为服务器；主机信息和密码之后会
像其他服务器凭据一样保存在设备上。

## 在本机执行命令

**在本机执行命令**位于 **设置 → 应用 → AI**，与服务器操作分开，默认关闭。开启后，本机
命令仍不会自动执行：每条命令都需要你确认，即使它看起来只读，或你已开启**自动执行只读
命令**。

执行目标因平台而异：

- **桌面端：**运行 Server Box 的计算机，包括该计算机上的文件。
- **Android 和 iOS：**App 提供的 Alpine Linux 环境，无法访问手机自身的文件系统、App 数据
  或用户文件。详见[本机终端](/docs/zh/advanced/local-terminal/)。

无法执行本机命令的平台不会显示此选项。App Store 版 macOS 受沙盒限制，无法启动 shell；
未包含 Linux engine 的 iOS 版本也不支持本机命令。

## 对话历史

Agent 标签页的对话保存在本机，可从历史记录页面重新打开或全部清除。对话和工具结果可能
包含命令输出、文件内容以及你选中的终端文本；这些内容会在用于对话时发送给配置的 model。

## 发送消息前

- 模型可能给出错误建议或命令。执行前请逐项审核。
- 为了让模型分析问题，命令输出、读取的文件内容和选中的终端文本可能会发送给 provider。
  发送消息或批准工具操作前，请检查其中是否包含敏感信息。
- 默认按 **Enter** 发送，按 **Shift+Enter** 换行。可在 **设置 → 应用 → AI → 回车发送**
  中更改此设置。
