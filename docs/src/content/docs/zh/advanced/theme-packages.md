Server Box 内置 Default 和 AMOLED 两款主题，也支持从主题商店或主题文件安装更多主题，
例如 One Dark Pro。主题相关设置位于
**设置 → 外观**。Monitor 面板使用同样的主题包，见
[在 Monitor 面板中使用](#在-monitor-面板中使用)。

## 选择主题

打开 **主题预设**，即可选择内置主题、已安装的主题或 **自定义**。在列表中移动焦点
时会预览主题，但不会保存更改。选中主题后即可应用；关闭选择器则保留打开前使用的主题。

部分主题包含多个变体，例如 Pride 的 Trans、Nonbinary 和 Rainbow。每个变体会单独列出，
显示为 `Pride · Trans`，可以像其他主题一样选择。整个主题包的所有变体只需安装和更新一次。

**自定义** 支持选择本地背景图，并调整应用内图标、圆角、不透明度和模糊度。这些选项独立于主题包中的只读设置。

主题会声明支持的外观模式。同时支持浅色和深色模式的主题可配合“跟随系统”、“浅色”或“深色”使用；仅支持单一模式的主题在选中期间会锁定外观模式。

AMOLED 是内置主题，深色模式下使用纯黑背景，浅色模式下使用标准浅色配色。

## 安装主题

打开 **设置 → 外观 → 安装主题**，选择以下来源之一：

- **文件**：选择 `.fsbt` 主题包。
- **URL**：通过 HTTPS 链接安装主题包。
- **文件夹**（桌面端）：导入主题目录，适合开发和预览主题时使用。

安装完成后，主题会立即应用，并出现在 **主题预设** 中。再次安装已安装的主题（例如
新版本，或修改后重新导入的主题文件夹）会替换之前的安装；若该主题正在使用，会保持选中
新安装的版本。其他已安装的主题不受影响。

## 浏览主题商店

打开 **设置 → 外观 → 主题商店**，浏览主题目录。已安装的目录主题会与本地记录合并显示。点按未安装的主题即可下载并启用；点按已安装的主题即可直接切换。条目右侧按钮可根据当前状态执行安装或移除；移除当前正在使用的主题后，应用会自动切回默认主题。

点按条目上的展开按钮可在安装前预览主题效果。预览会应用该主题的配色、组件样式、背景和图标，可通过顶部分段按钮在浅色与深色模式或不同变体之间切换。关闭主题商店时会自动清理预览缓存文件。

对于已安装且包含多个变体的主题，可在条目内直接点击分段按钮切换变体。

主题商店会缓存最近一次加载的列表，离线时仍可浏览。标题栏下方显示上次刷新时间，点击刷新按钮或下拉列表即可检查更新。搜索支持匹配主题名称、变体名称、多语言简介及仓库名称。

## 在 Monitor 面板中使用

[Monitor](/docs/zh/advanced/monitor-agent/) 的网页面板支持相同的 `.fsbt` 主题包。面板主题随账号保存在 Monitor 服务器上，在任意浏览器中登录都会生效，与 App 本地安装的主题互不影响。

在面板中打开 **设置 → 外观 → 主题**：

- 选择 **默认** 使用桌面自带配色，或选择任意已安装的主题。带变体的主题包会分别列出各个变体（如 `Pride · Trans`）。
- **安装主题 → 从文件** 可上传本地 `.fsbt` 主题包，Monitor 会在校验通过后完成安装。
- **主题商店** 列出官方目录中的主题，由 Monitor 通过 HTTPS 下载并校验 SHA-256 后安装。已安装主题有新版本时会显示 **更新** 按钮。
- 点击主题旁的移除按钮可卸载主题；卸载当前主题后会自动恢复为 **默认**。

仅支持深色或浅色的主题在选中期间会锁定面板外观模式；两种模式均支持的主题会在选中时自动切换到其默认模式。带有背景图的主题会将背景图设为桌面壁纸，你也可以在同一页面的壁纸选项中单独更换。每个账号最多可安装 32 个主题（总计不超过 128 MiB）。

## 制作主题

主题包以目录形式开发，包含 `manifest.toml` 与可选图片资源；分发时打包为 `.fsbt` 文件或发布至主题仓库。包格式与发布流程请参阅[主题包制作](/docs/zh/development/theme-authoring/)。
