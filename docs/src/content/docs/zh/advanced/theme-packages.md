Server Box 内置 Default 和 AMOLED 两款主题，也支持从主题商店或主题文件安装更多主题，
例如 One Dark Pro。主题相关设置位于
**Settings → Appearance**。Monitor 面板使用同样的主题包，见
[在 Monitor 面板中使用](#在-monitor-面板中使用)。

## 选择主题

打开 **Theme preset**，即可选择内置主题、已安装的主题或 **Custom**。在列表中移动焦点
时会预览主题，但不会保存更改。选中主题后即可应用；关闭选择器则保留打开前使用的主题。

部分主题包含多个变体，例如 Pride 的 Trans、Nonbinary 和 Rainbow。每个变体会单独列出，
显示为 `Pride · Trans`，可以像其他主题一样选择。整个主题包的所有变体只需安装和更新一次。

**Custom** 支持选择本地背景图，并调整应用内 icon、圆角、不透明度和模糊度。这些选项
独立于主题包中的只读设置。

主题会声明支持的外观模式。支持 Light 和 Dark 两种模式的主题可以配合 System、Light 或
Dark 使用。只支持一种模式的主题会锁定模式设置。若要自由切换模式，请选择同时支持
Light 和 Dark 的主题。

AMOLED 是内置主题。Dark 模式使用纯黑表面，Light 模式使用标准浅色配色。TODO：支持的升级范围不再包含旧版 AMOLED 设置后，删除相应的迁移逻辑。

## 安装主题

打开 **Settings → Appearance → Install theme**，选择以下来源之一：

- **File**：选择 `.fsbt` 主题包。
- **URL**：通过 HTTPS 链接安装主题包。
- **Folder**（桌面端）：导入主题目录，适合开发和预览主题时使用。

安装完成后，主题会立即应用，并出现在 **Theme preset** 中。再次安装已安装的主题（例如
新版本，或修改后重新导入的主题文件夹）会替换之前的安装；若该主题正在使用，会保持选中
新安装的版本。其他已安装的主题不受影响。

## 浏览主题商店

打开 **Settings → Appearance → Theme store**，浏览主题 catalog 中的内容。catalog 中
已安装的主题会与本机记录合并显示在同一项中。选择未安装的主题即可下载并应用；选择已
安装的主题即可应用。主题旁的按钮会根据当前状态提供安装或移除操作。移除正在使用的主题
后，应用会切回默认主题。

点按条目上的展开按钮，可在安装前预览主题。预览会使用该主题的配色、组件样式、背景和
icon，上方的分段按钮用于在 Light 和 Dark 之间、以及主题包的各个变体之间切换。未安装的主题会为预览
下载，并与安装时一样校验，但不会安装或应用。预览默认折叠；关闭主题商店时会删除为预览
下载的文件。

对于已安装且包含变体的主题，条目中会显示分段按钮，每个变体对应一段，选择即可应用该变体。

主题商店会在应用重启后保留最近读取的结果，因此离线时仍能看到之前加载的主题。标题栏
下方会显示上次更新时间；catalog 主题的条目会显示其 repository 和版本。点按标题栏中的
刷新按钮或下拉列表可检查更新。主题提供了对应语言的简介时，会按应用语言显示。搜索会
匹配主题名称、变体名称、任一语言的简介和 repository 名称；排序菜单
可以将当前主题置顶，或按名称排序。

商店中有比已安装版本更新的版本时，条目上会显示更新按钮。更新会替换已安装的版本；若该
主题正在使用，更新后仍保持使用。

部分主题可能需要较新版本的应用才能安装。这些主题仍会显示在商店中，并说明无法安装的
原因。

## 在 Monitor 面板中使用

[Monitor agent](/docs/zh/advanced/monitor-agent/) 的网页面板使用和 App 相同的
`.fsbt` 主题包。面板中的主题按账号保存在 agent 上，从任何浏览器登录都会生效，
与 App 中安装的主题互不影响。

在面板中打开 **Settings → Appearance → Themes**：

- 选择 **Default** 使用桌面自身的配色，或选择一个已安装的主题。带变体的主题包会
  分别列出每个变体，例如 `Pride · Trans`。
- **Install a theme → From file** 上传一个 `.fsbt` 主题包。agent 使用与 App 相同的
  代码读取并检查它，检查不通过的主题包会被拒绝。
- **Theme store** 列出 ServerBox 目录中的主题。agent 通过 HTTPS 下载主题包，校验
  SHA-256 后再安装；面板无法让 agent 从其他地址下载。需要更新版本 agent 的主题会
  显示出来，但无法安装。已安装主题有新版本时显示 **Update**。
- 主题旁的删除按钮用于移除主题。移除正在使用的主题后，桌面恢复为 **Default**。

只支持深色或只支持浅色的主题，在选中期间会锁定面板的外观模式；两种模式都支持的主题，
选中时会切换到它的首选模式。选中带背景图的主题后，背景图会成为桌面墙纸；同一页面中的
墙纸选项可以替换它。每个账号最多安装 32 个主题，合计最多 128 MiB。

## 制作主题

主题包以目录形式制作，包含 `manifest.toml` 和可选图片；分享时可打包为 `.fsbt` 文件，
也可以发布到 theme repository。包格式和发布流程请参阅[主题制作指南](/docs/zh/development/theme-authoring/)。
