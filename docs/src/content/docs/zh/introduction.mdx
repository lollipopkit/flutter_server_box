Server Box 是一款使用 Flutter 构建的跨平台服务器管理应用。你可以用它远程监控和管理 Linux、Unix 及 Windows 服务器。

## Server Box 是什么？

Server Box 为常见的服务器管理任务提供统一界面，适合系统管理员、开发者以及运行家庭服务器的用户。

连接服务器有两种方式：使用 **SSH**，或使用服务器上运行的 **[Monitor agent](/docs/zh/advanced/monitor-agent/)**。SSH 不需要在服务器上安装额外软件，并支持完整功能。Monitor agent 适合不方便开放 SSH 端口的服务器；它会持续保存监控历史，因此即使 App 之前没有连接过，打开图表时也能看到历史数据。

同一台服务器可以同时配置 SSH 和 Monitor agent。App 会按照设置的优先顺序尝试连接，并在需要时使用另一种方式；两种方式各自提供的功能也会保留。

## 核心功能

- **实时监控**：查看 CPU、内存、磁盘使用率、网络速度、GPU 状态和系统温度
- **SSH 终端**：访问功能完整的终端，支持多标签页和自定义外观
- **SFTP 客户端**：浏览和管理服务器文件
- **容器管理**：管理 Docker 和 Podman 容器
- **进程管理**：查看和管理系统进程
- **Systemd 服务**：启动、停止和监控 systemd 服务
- **网络工具**：运行 iPerf、Ping 和网络唤醒（WoL）
- **代码片段**：保存并执行自定义 Shell 命令
- **[Agent](/docs/zh/advanced/agent/)**：让模型诊断和操作服务器，每个操作都需要先确认

## 支持平台

- **移动端**：iOS 和 Android
- **桌面端**：macOS、Linux 和 Windows
- **配套应用**：watchOS
