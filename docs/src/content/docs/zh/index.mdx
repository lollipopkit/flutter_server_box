## 主要功能

<CardGrid stagger>
	<Card title="实时监控" icon="chart">
		查看 CPU、内存、磁盘、网络、GPU 和温度的实时数据与图表。
	</Card>
	<Card title="SSH 终端" icon="terminal">
		通过功能完整的 SSH 终端管理服务器，支持多标签页和移动端虚拟键盘。
	</Card>
	<Card title="SFTP 文件浏览器" icon="folder">
		使用内置的 SFTP 客户端和本地文件浏览器管理服务器文件。
	</Card>
	<Card title="容器管理" icon="box">
		直接在应用中启动、停止和监控 Docker 或 Podman 容器。
	</Card>
	<Card title="跨平台" icon="device-mobile">
		支持 iOS、Android、macOS、Linux、Windows 和 watchOS。
	</Card>
	<Card title="多语言" icon="globe">
		提供多种语言的界面和本地化支持。
	</Card>
</CardGrid>
