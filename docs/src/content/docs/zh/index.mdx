## 特性

<CardGrid stagger>
	<Card title="实时监控" icon="chart">
		通过实时图表监控 CPU、内存、磁盘、网络、GPU 和温度。
	</Card>
	<Card title="SSH 终端" icon="terminal">
		全功能 SSH 终端，支持多标签页和移动端虚拟键盘。
	</Card>
	<Card title="SFTP 文件浏览器" icon="folder">
		使用内置 SFTP 客户端和本地文件浏览器管理服务器上的文件。
	</Card>
	<Card title="容器管理" icon="box">
		在应用中启动、停止和监控 Docker 和 Podman 容器。
	</Card>
	<Card title="跨平台" icon="device-mobile">
		支持 iOS、Android、macOS、Linux、Windows 和 watchOS。
	</Card>
	<Card title="12+ 种语言" icon="globe">
		提供英语、中文、德语、法语等多种语言的本地化支持。
	</Card>
</CardGrid>
